Онлайн-хранилище SoundFont доступно прямо из Polyphone: в нём можно скачивать, пробовать и при необходимости повторно использовать SoundFont.


## Доступ к хранилищу {#doc_access}


Чтобы открыть онлайн-хранилище, нажмите :guilabel:`Онлайн-хранилище` или введите ключевое слово в поле поиска на [начальном экране](manual/index.md) и нажмите :kbd:`Enter`.
Когда онлайн-хранилище открыто в новой вкладке, отображается список SoundFont, доступных для загрузки; результаты можно искать, сортировать и фильтровать.
Результаты показываются по 25 на странице, а кнопки внизу позволяют перейти на предыдущую или следующую страницу.


![Онлайн-хранилище](images/online_repository.png "Онлайн-хранилище")


### Поиск SoundFont


Чтобы найти SoundFont, введите текст в верхней строке: список обновляется по мере ввода и показывает только SoundFont, в названии которых есть этот текст.
Можно ввести :command:`Author:"someone"`, чтобы найти SoundFont определённого автора (между двойными кавычками нужно указать точное имя автора).
Это можно сочетать с текстом для поиска в названии, например :command:`piano Author:"someone"`.


### Сортировка результатов


Рядом со строкой поиска раскрывающееся меню предлагает 4 способа сортировки SoundFont:

Дата
: Сначала самые новые SoundFont (выбор по умолчанию).

Загрузки
: Сначала самые скачиваемые SoundFont.

Рейтинг
: Сначала SoundFont с самой высокой оценкой.

Заголовок (А→Я)
: SoundFont сортируются в алфавитном порядке.


### Фильтрация результатов


Результаты можно фильтровать по-разному, причём для каждого фильтра можно выбрать несколько значений. Кнопка :guilabel:`Сброс` отменяет все фильтры.

Категория
: Вид инструмента.

Лицензия
: Можно вывести SoundFont, лицензия которых разрешает коммерческое использование и / или распространение после редактирования SoundFont.

Источник семплов
: Происхождение семплов.

Жанр
: Жанр, на который рассчитан SoundFont.

Стандарт MIDI
: Можно вывести только SoundFont, соответствующие [стандарту MIDI](manual/annexes/midi-standards.md).

Ярлыки
: Показ SoundFont с определённым ярлыком.


## Описание SoundFont {#doc_description}


Описание SoundFont открывается двойным щелчком (или клавишей :kbd:`Enter`) по ячейке в разделе :guilabel:`Ежедневные SoundFont` на [начальном экране](manual/index.md#doc_right) или в [списке SoundFont](#doc_access).
Для SoundFont, не входящих в :guilabel:`Ежедневные SoundFont`, требуется [премиум-аккаунт](premium).
Polyphone можно подключить к вашей учётной записи в [настройках](manual/settings.md#doc_repository) программы.


![Страница описания SoundFont](images/online_repository_description.png "Страница описания SoundFont")


Описание SoundFont состоит из:

* **заголовка**, в котором указаны название, количество комментариев, количество загрузок и оценка,
* **левой части** с именем автора, датой, типом лицензии (обратите на него внимание), категорией и другими атрибутами, характеризующими SoundFont,
* **центральной части** с текстовым описанием, списком файлов для загрузки и комментариями, если они есть.


## Загрузка {#doc_download}


Чтобы скачать файл, нажмите значок :guilabel:`Загрузить` рядом с именем файла в разделе :guilabel:`Загрузки`.
Ход загрузки отображается в меню рядом с [главным меню](manual/menu.md), в правом верхнем углу программы.
Файлы сохраняются в каталог загрузок, заданный в [настройках](manual/settings.md#doc_repository).
Если загруженный файл является SoundFont, его можно открыть в [редакторе SoundFont](manual/soundfont-editor/index.md), нажав значок :guilabel:`Открыть`.

Из меню можно очистить завершённые загрузки.
Если очистить всё, меню загрузок исчезает.


![Загрузка SoundFont](images/online_repository_download.png "Загрузка SoundFont")
