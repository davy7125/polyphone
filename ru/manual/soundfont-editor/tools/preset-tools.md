### Объединить семплы для каждой ноты {#doc_mergesamples}

Если при нажатии клавиши пресет одновременно вызывает несколько инструментов и семплов, эта функция объединяет для каждой ноты все звучащие семплы. В результате получается новый пресет, который воспроизводит только один семпл на клавишу, что снижает нагрузку на процессор, необходимую для воспроизведения пресета.
Окно запрашивает имя нового пресета, длительность поддержки и длительность затухания записываемых звуков, интервал между создаваемыми семплами (для каждой клавиши, каждые 3 клавиши или каждые 6 клавиш), автопетлю и тип звука (моно или стерео).

С параметрами, показанными на рисунке ниже, функция будет имитировать нажатие клавиши длительностью 5 секунд для каждой 3-й ноты. Запись будет стереофонической, а затухание записываться не будет. Созданные семплы затем будут зациклены с помощью [функции автопетли](manual/soundfont-editor/tools/sample-tools.md#doc_autoloop), а инструмент, содержащий все эти семплы, и новый пресет, который его использует, получат имя «Cymbale III».

**Примечание:** параметр автопетли удаляет часть затухания и немного сокращает длительность поддерживаемой части каждого семпла.
