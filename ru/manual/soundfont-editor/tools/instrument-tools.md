Если в [дереве](manual/soundfont-editor/tree.md) выбран инструмент или его разделы, [меню функций](manual/soundfont-editor/tools/index.md) предлагает функции 4 категорий:

* [анализ](#doc_cat_analyze),
* [быстрая правка](#doc_cat_fast),
* [модуляторы](#doc_cat_mod),
* [преобразование](#doc_cat_transformation).

За исключением создания аккордов и микстур, а также показа параметров, функции можно применять сразу к нескольким инструментам (при множественном выборе).


## Анализ {#doc_cat_analyze} 


### Показать параметры {#doc_display}


Эта функция показывает, как параметр меняется в зависимости от клавиши.
Легенда различает значения, заданные в глобальном разделе, значения, заданные в каждом разделе, и значение параметра по умолчанию.
Доступна логарифмическая шкала (осторожно со значениями, меньшими или равными 0!).


![Функция «Показать параметры»](images/tool_display_parameters.png "Функция «Показать параметры»")


## Быстрая правка {#doc_cat_fast}


### Изменить приглушение {#doc_attenuation}


Эта функция вычисляет минимальное и максимальное приглушение всех выбранных инструментов и позволяет добавить смещение ко всем значениям приглушения, не выходя за верхнюю и нижнюю границы.

Например, если наименьшее приглушение среди разделов выбранных инструментов равно 16 дБ, а нужно, чтобы минимальное приглушение было 5 дБ (чтобы повысить общую громкость), можно уменьшить приглушение всех разделов всех инструментов на 11 дБ.


![Функция «Изменить приглушение»](images/tool_change_attenuation.png "Функция «Изменить приглушение»")


### Расстройка {#doc_detune}


Эта функция слегка расстраивает ноты инструмента, чтобы вместе с правильно настроенным инструментом получить эффект биений (как у регистра «селеста»).
Сила эффекта выражается в биениях в секунду; можно настроить:

* количество биений в секунду на клавише 60 (до первой октавы, в середине клавиатуры; знак этого числа определяет направление расстройки),
* изменение количества биений в зависимости от ноты: на каждую октаву количество биений делится или умножается на определённый коэффициент (при значении «1» количество биений одинаково на всей клавиатуре).


![Функция «Расстройка»](images/tool_detune.png "Функция «Расстройка»")


Пример <a href="files/celeste_tuning_off.mp3" download>настроенного</a> инструмента.

![](files/celeste_tuning_off.mp3)

Этот инструмент вместе со своей <a href="files/celeste_tuning_on.mp3" download>расстроенной</a> копией.

![](files/celeste_tuning_on.mp3)

### Настройка по клавишам {#doc_global}


Эта функция позволяет одновременно редактировать параметры всех разделов инструмента в зависимости от диапазона клавиш каждого раздела.


![Функция «Настройка по клавишам»](images/tool_keybased_configuration.png "Функция «Настройка по клавишам»")


График показывает величину изменения: первое значение слева соответствует изменению, применяемому к разделу с клавишей 0, а последнее значение справа — к разделу с клавишей 127.
Минимум и максимум графика настраиваются.
Изменяя шаблон, можно редактировать кривую:

Вручную
: Кривая рисуется мышью.

Линейное возрастание / Линейное убывание
: Кривая — прямая линия.

Экспоненциальное возрастание / Экспоненциальное убывание
: Кривая — экспонента, изгиб которой задаётся параметром :guilabel:`Жёсткость`.

Случайно
: Значения генерируются случайным образом в соответствии с параметром :guilabel:`Распределение`.

При линейном или экспоненциальном законе щелчок левой кнопкой по графику задаёт начало линейной или экспоненциальной области, а щелчок правой кнопкой — её конец.

Изменяемый параметр выбирается в поле :guilabel:`Параметр`, а тип изменения — в поле :guilabel:`Изменение`:

Добавление
: Значение изменения прибавляется к значению выбранного параметра.

Умножение
: Значение выбранного параметра умножается на значение изменения.

Замена
: Значение изменения заменяет значение выбранного параметра.

Изменение можно также применить только к разделам, диапазон силы нажатия которых лежит в определённых пределах, например в случае фортепиано с несколькими слоями силы нажатия.


### Естественное затухание {#doc_release}


Эта функция создаёт затухание для каждого раздела инструмента.
Время затухания вычисляется по первым двум параметрам (время затухания на клавише 36 и коэффициент между соседними октавами, :guilabel:`Деление на следующую октаву`); с помощью третьего параметра (:guilabel:`Вызываемая расстройка (полутона)`) можно также добавить изменение высоты тона.


![Функция «Естественное затухание»](images/tool_natural_release.png "Функция «Естественное затухание»")


### Автопозиционирование семплов {#doc_position}


Программа задаёт диапазоны клавиш всех разделов инструмента так, чтобы оптимально использовать клавиатуру.
Это также происходит автоматически, когда с пустым инструментом связываются несколько семплов с разными корневыми клавишами.


### Пространственная локализация звука {#doc_spatialization}


Эта функция распределяет звуки в пространстве в зависимости от их высоты, что полезно, например, для фортепиано (от низких звуков к высоким, слева направо).


![Функция «Пространственная локализация звука»](images/tool_sound_spatialization.png "Функция «Пространственная локализация звука»")


Каждая полоса графика изображает струну или трубу, длина которой связана с высотой звука.
Самая короткая полоса соответствует самому высокому звуку, самая длинная — самому низкому.

Каждая нота располагается в пространстве: крайнее левое положение соответствует звуку, слышимому слева, крайнее правое — звуку, слышимому справа.
Доступны следующие шаблоны:

По возрастанию
: Высокие звуки слева, низкие справа.

По убыванию
: Низкие звуки слева, высокие справа.

Впадина
: Низкие звуки по краям, высокие в центре.

Пик
: Высокие звуки по краям, низкие в центре.

Случайно
: Высокие и низкие звуки распределяются случайным образом.

Доступны и другие параметры:

* количество повторений шаблона (:guilabel:`Количество делений`),
* сила эффекта (:guilabel:`Разброс (%)`),
* заполнение разделов (:guilabel:`Заполнение (%)`),
* смещение влево или вправо, если разброс меньше 100% (:guilabel:`Смещение (0-100)`),
* :guilabel:`Инверсии`.

График обновляется при каждом изменении настроек, поэтому результат легко оценить.
При наведении мыши показывается соответствие между номером ноты и панорамой.


### Транспонирование {#doc_transpose}


Функция транспонирования позволяет транспонировать весь инструмент.
Звучание инструмента остаётся прежним, но меняется его положение на клавиатуре.

На входе требуется сдвиг в полутонах.
Чтобы звук стал выше, сдвиг должен быть положительным.
Чтобы звук стал ниже, сдвиг, наоборот, должен быть отрицательным.
Для каждого раздела инструмента функция выполняет следующие действия:

* корректирует корневую клавишу,
* изменяет точную подстройку, если транспонирование выполняется на нецелое число полутонов,
* сдвигает диапазон клавиш на соответствующее число полутонов, если отмечен параметр :guilabel:`Адаптировать диапазон клавиш`.


![Функция «Транспонирование»](images/tool_transpose_inst.png "Функция «Транспонирование»")


## Модуляторы {#doc_cat_mod}


### Переопределить модулятор по умолчанию {#doc_default_mod}


Каждому инструменту автоматически назначаются модуляторы по умолчанию.
Эта функция показывает их список и позволяет создать модуляторы, которые переопределяют или отключают выбранные модуляторы (кнопки :guilabel:`Переопределить` и :guilabel:`Отключить`).


![Функция переопределения](images/tool_default_mod.png "Функция переопределения")


### Удалить модуляторы {#doc_remove_mod}


Удаляются все модуляторы всех выбранных инструментов.
Сообщение показывает, сколько модуляторов было удалено.

**Примечание:** модуляторы по умолчанию продолжают действовать.
Единственный способ их отключить — переопределить их с помощью функции «[Переопределить модулятор по умолчанию](#doc_default_mod)».


## Преобразование {#doc_cat_transformation}


### Создать аккорды {#doc_chords}


Эта функция позволяет создать на основе инструмента все возможные аккорды.
Это полезно, например, для создания хоров или пэдов.

Аккорды задаются выбором входящих в них звуков (прима, терция, квинта, септима, нона) с их видом (большая, малая, чистая, уменьшённая, увеличенная), количеством обращений и октавой.
Семплы с аккордами создаются для каждой клавиши, каждой 3-й или каждой 6-й клавиши, с автопетлёй или без неё, в моно или стерео.


![Функция «Создать аккорды»](images/tool_create_chords.png "Функция «Создать аккорды»")

### Дублирование раздела {#doc_division}


Эта операция дублирует все разделы инструмента.
Например, если у семпла, связанного с инструментом, диапазон клавиш 36-38, программа продублирует этот раздел так, что семпл будет назначен диапазонам клавиш 36-36, 37-37 и 38-38.
Это позволяет тонко редактировать параметры семпла для каждой ноты, а не для целого раздела с одинаковыми параметрами.

Разделы можно дублировать и по диапазонам силы нажатия.
Инструменты без семплов несовместимы с этой функцией.


![Функция «Дублирование раздела»](images/tool_division_duplication.png "Функция «Дублирование раздела»")


### Создание микстуры {#doc_mixture}


Эта функция, предназначенная для органа, позволяет создать микстуру на основе существующего инструмента.
Появляется окно, в котором задаются разделы микстуры и для каждого из них — список рядов.
Возможные типы рядов очень разнообразны: от октавы до 27-й гармоники.


![Функция «Создание микстуры»](images/tool_mixture.png "Функция «Создание микстуры»")


Функция работает со всеми семплами, связанными с выбранным инструментом, диапазонами, заданными для каждого семпла, и соответствующими приглушениями.
Семплы должны быть настроены независимо от определения инструмента (в [редакторе семплов](manual/soundfont-editor/editing-pages/sample-editor.md)), а указанная корневая клавиша не должна отражать принадлежность к регистру (например, без транспонирования, даже если звук — принципал 4').

Один параметр позволяет создавать семплы с автопетлёй, другой — задать, для каких клавиш создавать семплы (для каждой клавиши, каждые 3 клавиши, каждые 6 клавиш).
Наконец, можно выбрать тип создаваемого звука (моно или стерео).
