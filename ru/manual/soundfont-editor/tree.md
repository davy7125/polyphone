Дерево — первый элемент редактора, с которым стоит разобраться.
Оно отражает структуру открытого SoundFont и управляет правой частью программы, когда вы выбираете один или несколько элементов.

Дерево всегда отображается с одной и той же [структурой](#doc_structure), предоставляет [контекстное меню](#doc_menu) и поддерживает [перетаскивание](#doc_dragdrop), [копирование / вставку](#doc_copypaste) и [поиск](#doc_search).


## Структура {#doc_structure}


Дерево состоит из 4 заголовков; у заголовков :guilabel:`Семплы`, :guilabel:`Инструменты` и :guilabel:`Пресеты` есть вложенные элементы.


![Дерево: структура](images/tree_1.png "Дерево: структура")


### Заголовок «Общее»


Щелчок по заголовку :guilabel:`Общее` открывает редактор [общей информации](manual/soundfont-editor/editing-pages/editing-of-the-general-information.md).


### Раздел «Семплы»


В этом разделе перечислены все семплы SoundFont — исходный материал, на основе которого строятся все инструменты.
Выбор одного или нескольких семплов открывает [редактор семплов](manual/soundfont-editor/editing-pages/sample-editor.md).
Щелчок по заголовку :guilabel:`Семплы` показывает [сводку конфигурации](manual/soundfont-editor/configuration-summaries.md#doc_sample) всех семплов.


### Раздел «Инструменты»


В этом разделе перечислены все инструменты SoundFont; инструмент — это промежуточный элемент, состоящий из семплов и используемый пресетами.
Инструменты содержат ссылки на семплы, называемые «разделами» (divisions); они отображаются списком под каждым инструментом.
Выбор инструмента или одного из его разделов открывает [редактор инструментов](manual/soundfont-editor/editing-pages/instrument-editor.md).
Щелчок по заголовку :guilabel:`Инструменты` показывает [сводку конфигурации](manual/soundfont-editor/configuration-summaries.md#doc_instrument) всех инструментов.


### Раздел «Пресеты»


В этом разделе перечислены все пресеты SoundFont; пресет — это конечный элемент, состоящий из инструментов и доступный извне SoundFont.
Пресеты содержат ссылки на инструменты, называемые «разделами»; они отображаются списком под каждым пресетом.
Выбор пресета или одного из его разделов открывает [редактор пресетов](manual/soundfont-editor/editing-pages/preset-editor.md).
Щелчок по заголовку :guilabel:`Пресеты` показывает [сводку конфигурации](manual/soundfont-editor/configuration-summaries.md#doc_preset) всех пресетов.


## Контекстное меню {#doc_menu}


Щелчок правой кнопкой мыши по элементу открывает меню со следующими действиями:

Связать с…
: Связывает выбранные семплы с инструментом или выбранные инструменты с пресетом.
  Цель выбирается в списке, который можно фильтровать.
  Если с пустым инструментом связываются семплы с разными корневыми клавишами, их диапазоны клавиш задаются автоматически (как с функцией [Автопозиционирование семплов](manual/soundfont-editor/tools/instrument-tools.md#doc_position)).

Заменить на…
: Заменяет семпл другим семплом в разделе инструмента или инструмент другим инструментом в разделе пресета.
  Настройки раздела сохраняются.

Копировать
: Копирует выбранные элементы; также доступно по :kbd:`Ctrl`+:kbd:`C`.

Вставить
: Вставляет ранее скопированные элементы; также доступно по :kbd:`Ctrl`+:kbd:`V`.

Дублировать
: Дублирует выбранные элементы — семплы, инструменты, пресеты или разделы.
  Также доступно по :kbd:`Ctrl`+:kbd:`D`.

Удалить
: Удаляет выбранные элементы; также доступно по :kbd:`Del`.
  Семпл, используемый инструментом, и инструмент, используемый пресетом, удалить нельзя.

Заглушить
: Для проверки можно заглушить раздел внутри инструмента или пресета. Этот параметр также есть в контекстном меню [заголовка таблицы](manual/soundfont-editor/editing-pages/instrument-editor.md#doc_solo).

Всегда играть
: В противоположность функции «Заглушить», при игре можно добавить один или несколько инструментов или пресетов. Так можно подобрать хороший баланс между разными инструментами или пресетами, звучащими вместе.

Восстановить воспроизведение
: Отменяет действие «Заглушить» и «Всегда играть» во всём SoundFont.

Переименовать или массовое переименование
: Переименовывает выбранные элементы; также доступно по :kbd:`F2`.
  Переименование раздела переименовывает семпл или инструмент, с которым он связан.
  Если выбрано несколько элементов, диалоговое окно предлагает разные варианты:
  
  * перезаписать имя с именем клавиши в качестве суффикса (только для семплов и разделов инструментов),
  * перезаписать имя с именем клавиши и силой нажатия в качестве суффикса (только для разделов инструментов),
  * перезаписать имя с числовым суффиксом по возрастанию,
  * заменить символы,
  * вставить текст в определённую позицию,
  * удалить диапазон символов.


![Дерево: контекстное меню](images/tree_2.png "Дерево: контекстное меню")


## Перетаскивание {#doc_dragdrop}


Перетаскивание в дереве позволяет быстро создавать связи или копии.
Перед перетаскиванием нужно выбрать элементы.
Это может быть один элемент или множественный выбор с помощью клавиш :kbd:`Ctrl` и :kbd:`Shift`.

Результат перетаскивания зависит от типа перетаскиваемых элементов и типа целевого элемента.

Семпл → инструмент
: Связывание семпла с инструментом, создание раздела инструмента.

Семпл → заголовок :guilabel:`Инструменты`
: Создание инструмента, содержащего все перетащенные семплы, или создание отдельного инструмента для каждого перетащенного семпла.

Инструмент → пресет
: Связывание инструмента с пресетом, создание раздела пресета.

Инструмент → инструмент
: Копирование всех разделов исходного инструмента в целевой инструмент (это может быть тот же инструмент).

Раздел инструмента → инструмент или раздел инструмента
: Копирование выбранных разделов исходного инструмента в целевой инструмент (это может быть тот же инструмент).

Инструмент → заголовок :guilabel:`Пресеты`
: Создание пресета, содержащего все перетащенные инструменты, или создание отдельного пресета для каждого перетащенного инструмента.

Пресет → пресет
: Копирование всех разделов исходного пресета в целевой пресет (это может быть тот же пресет).

Раздел пресета → пресет или раздел пресета
: Копирование выбранных разделов исходного пресета в целевой пресет (это может быть тот же пресет).

Аудиофайл (из файлового менеджера компьютера) → дерево
: Импорт файла как нового семпла, если его формат поддерживается (см. [редактор семплов](manual/soundfont-editor/editing-pages/sample-editor.md)).


## Копирование / вставка {#doc_copypaste}


Всё, что можно сделать перетаскиванием, как описано выше, можно сделать и копированием / вставкой — через контекстное меню или сочетаниями клавиш :kbd:`Ctrl`+:kbd:`C` и :kbd:`Ctrl`+:kbd:`V`.

Копирование / вставка возможны и между разными SoundFont.
Можно скопировать элемент в одном SoundFont и вставить его в другой.
Допускается множественный выбор.

Выбраны семплы
: Копирование семплов.

Выбраны инструменты
: Копирование инструментов вместе со всеми связанными семплами.

Выбраны пресеты
: Копирование пресетов вместе со всеми связанными инструментами и семплами.

Если при копировании элементов между разными SoundFont элемент с таким же именем уже существует, предлагается несколько вариантов:

* пропустить операцию — в этом случае копирование элемента с таким же именем отменяется;
* заменить существующий элемент — в этом случае существующий элемент перезаписывается скопированным;
* дублировать элемент — в этом случае элемент копируется рядом с существующим под другим именем.


## Поиск {#doc_search}


Для облегчения поиска элементов в дереве есть строка поиска, позволяющая их фильтровать (сочетание :kbd:`Ctrl`+:kbd:`F` переводит в неё фокус).


![Дерево: строка поиска](images/tree_3.png "Дерево: строка поиска")


Если в строку поиска ввести текст, отображаются элементы, которые его содержат.
Кроме того:

* если текст содержится в имени семпла, отображаются инструменты, использующие этот семпл, и пресеты, использующие эти инструменты;
* если текст содержится в имени инструмента, отображаются семплы, используемые инструментом, и пресеты, использующие этот инструмент;
* если текст содержится в имени пресета, отображаются инструменты, используемые пресетом, и семплы, используемые этими инструментами.

Щелчок по крестику справа от поля ввода отменяет фильтр.
