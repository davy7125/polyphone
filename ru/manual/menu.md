Меню в правом верхнем углу программы содержит несколько пунктов, открывающих доступ к различным функциям.


![Меню](images/menu.png "Меню")


## Открытие редактора SoundFont {#doc_open}


Создать
: Создаёт новый пустой SoundFont, в котором всё нужно делать с нуля.
  Также доступно по сочетанию :kbd:`Ctrl`+:kbd:`N`.

Открыть…
: Открывает файл [.sf2](manual/annexes/the-different-soundfont-formats.md#doc_sf2), [.sf3](manual/annexes/the-different-soundfont-formats.md#doc_sf3), [.sfz](manual/annexes/the-different-soundfont-formats.md#doc_sfz), [.sfArk](manual/annexes/the-different-soundfont-formats.md#doc_sfark) или [.organ](manual/annexes/the-different-soundfont-formats.md#doc_organ).
  Также доступно по сочетанию :kbd:`Ctrl`+:kbd:`O`.


## Сохранение SoundFont {#doc_save}


Сохранить
: Сохраняет текущий файл.
  Также доступно по сочетанию :kbd:`Ctrl`+:kbd:`S`.

Сохранить как…
: Сохраняет текущий файл в другой файл.
  Также доступно по сочетанию :kbd:`Ctrl`+:kbd:`Shift`+:kbd:`S`.

Экспортировать SoundFont…
: Объединяет и экспортирует один или несколько пресетов из открытых SoundFont в формате [.sf2](manual/annexes/the-different-soundfont-formats.md#doc_sf2), [.sf3](manual/annexes/the-different-soundfont-formats.md#doc_sf3) или [.sfz](manual/annexes/the-different-soundfont-formats.md#doc_sfz). Дополнительный формат .csv экспортирует все параметры для подробного анализа содержимого SoundFont.
  Также доступно по сочетанию :kbd:`Ctrl`+:kbd:`E`.


![Окно экспорта](images/export.png "Окно экспорта")


В окне экспорта перечислены пресеты всех открытых SoundFont; нужно отметить те, которые следует экспортировать (кнопки :guilabel:`Выбрать все` и :guilabel:`Снять выделение` помогают быстро изменить выбор).
Остальные параметры:

Назначение
: Каталог, в который записываются файлы.
  Файл никогда не перезаписывается: если файл с таким именем уже существует, к имени нового файла добавляется число.

Формат
: Один из форматов :guilabel:`.sf2`, :guilabel:`.sf3`, :guilabel:`.sfz` или :guilabel:`.csv`.
  Если пресеты взяты из нескольких SoundFont, они объединяются в один SoundFont, в котором каждый исходный SoundFont становится банком.
  Поэтому одновременно можно экспортировать не более 127 SoundFont, в каждом из которых выбрано не более 127 пресетов.

Качество
: Только для формата .sf3 — качество сжатия семплов.

Один файл на пресет
: Только для форматов .sf2 и .sf3 — создание отдельного файла для каждого выбранного пресета вместо одного общего файла.

Один каталог на банк, номер пресета в качестве префикса, классификация General MIDI
: Только для формата .sfz. При экспорте создаётся каталог с файлами sfz и подкаталогом :file:`samples`.
  Файлы sfz можно разложить по каталогам для каждого банка, добавить к их именам номер пресета и распределить по каталогам, соответствующим категориям General MIDI.

Сырые значения
: Только для формата .csv. Значения записываются так, как они хранятся в формате sf2, без перевода в обычные единицы (секунды, децибелы, центы и т. д.).
  При экспорте создаётся каталог с файлом :file:`samples.csv` и отдельными файлами для каждого инструмента и каждого пресета.


## Параметры просмотра {#doc_view}


На весь экран
: Включает и выключает полноэкранный режим.
  Также доступно по клавише :kbd:`F11`.


## Ярлыки {#doc_shortcuts}


Настройки
: Открывает [настройки](manual/settings.md) программы.
  Также доступно по сочетанию :kbd:`Ctrl`+:kbd:`,`.

Онлайн-руководство
: Показывает это руководство пользователя в веб-браузере.
  Также доступно по клавише :kbd:`F1`.

О программе Polyphone…
: Показывает версию программы и сведения об авторских правах. Кнопка :guilabel:`Участники` показывает список людей, внёсших вклад в проект.


## Закрытие {#doc_close}


Закрыть вкладку
: Закрывает текущую вкладку (редактор SoundFont, обозреватель SoundFont, настройки и т. д.).
  Также доступно по сочетанию :kbd:`Ctrl`+:kbd:`W`.

Выход
: Завершает работу программы.
  Также доступно по сочетанию :kbd:`Ctrl`+:kbd:`Q`.
