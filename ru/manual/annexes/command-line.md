Polyphone можно запускать из командной строки для преобразования SoundFont в формат [sf2](#doc_sf2), [sf3](#doc_sf3), [sfz](#doc_sfz), [csv](#doc_csv) или [dls](#doc_dls). Для преобразования поддерживаются форматы файлов [sf2](manual/annexes/the-different-soundfont-formats.md#doc_sf2), [sf3](manual/annexes/the-different-soundfont-formats.md#doc_sf3), [sfz](manual/annexes/the-different-soundfont-formats.md#doc_sfz), [dls](manual/annexes/the-different-soundfont-formats.md#doc_dls), [sfArk](manual/annexes/the-different-soundfont-formats.md#doc_sfark) и [organ](manual/annexes/the-different-soundfont-formats.md#doc_organ).

[MIDI-файл можно воспроизвести](#doc_render) с SoundFont и записать в wav-файл.
Также можно указать параметры для открытия Polyphone в [режиме синтезатора](#doc_synth) или с запущенным [сервером MCP](#doc_mcp).

Файлы и каталоги можно передавать в качестве аргументов, чтобы открыть их в графическом интерфейсе, например :command:`polyphone file1.sf2 file2.sf3 /path/to/directory` (каталог открывается в [обозревателе SoundFont](manual/soundfont-explorer.md)).
Если Polyphone уже открыт, файлы открываются в запущенном экземпляре.
Есть и несколько [других параметров](#doc_other) для сброса конфигурации или вывода справки и версии.

Список всех параметров выводится командой :command:`polyphone --help`.
Порядок аргументов не имеет значения.
Параметры [предыдущих версий](#doc_legacy) по-прежнему поддерживаются.

**Примечание:** в Windows вместо :command:`polyphone` нужно указать полный путь к Polyphone, например :command:`C:/Program files/Polyphone/polyphone.exe`.


## Преобразование {#doc_conversion}


### Командная строка


```
polyphone --convert <формат> <файлы/для/преобразования> -d <выходной/каталог> -o <выходной/файл> -f
```


### Аргументы


--convert
: Формат преобразования: «sf2», «sf3», «sfz», «csv» или «dls»; параметры, специфичные для каждого формата, описаны ниже.
  Этот аргумент необязателен, если выходной файл указан с расширением, например :command:`polyphone file.sf2 -o file.sf3`.

-d, --output-dir
: Выходной каталог, который должен существовать.
  Этот аргумент необязателен; по умолчанию используется каталог каждого входного файла.

-o, --output
: Выходной файл, с расширением или без него (расширение формата добавляется автоматически).
  Этот аргумент необязателен; по умолчанию выходной файл получает имя входного файла.
  Имя без пути записывается в выходной каталог, относительный путь отсчитывается от текущего каталога (или от выходного каталога, если используется -d).
  Этот аргумент нельзя использовать, если преобразуется несколько файлов.

-f, --force
: Заменяет существующий выходной файл.
  Без этого аргумента преобразование завершается с ошибкой, если выходной файл уже существует.
  Входной файл можно заменить результатом его преобразования, например :command:`polyphone --convert sf2 file.sf2 -f` перезаписывает :file:`file.sf2`.

Одной командой можно преобразовать несколько файлов, при этом каждый выходной файл получает имя своего входного файла.
В случае ошибки остальные файлы всё равно преобразуются.


### Примеры


```
polyphone --convert sf2 /path/to/file.sfArk
polyphone /path/to/file.sf2 -o /path/to/converted.sf3
polyphone --convert sf3 *.sf2 -d /path/to/directory
```


## Преобразование в sf2 {#doc_sf2}


Для этого преобразования особые параметры не используются.

```
polyphone --convert sf2 /path/to/file.dls
```


## Преобразование в sf3 {#doc_sf3}


--quality
: Качество сжатия: «low» (низкое), «medium» (среднее) или «high» (высокое).
  Этот аргумент необязателен; по умолчанию используется «medium».

```
polyphone --convert sf3 /path/to/file.sf2 --quality high
```


## Преобразование в sfz {#doc_sfz}


--preset-prefix
: К имени каждого пресета в начале добавляется его номер.

--bank-dir
: Для каждого банка создаётся отдельный каталог.

--gm-sort
: Для сортировки пресетов используется классификация General MIDI.

```
polyphone --convert sfz /path/to/file.sf3 --bank-dir --gm-sort
```

При преобразовании создаётся каталог (с именем выходного файла), содержащий файлы sfz и подкаталог :file:`samples`.
Если этот каталог уже существует, к его имени добавляется номер: ничего не заменяется, даже с -f.


## Преобразование в .csv {#doc_csv}


--raw
: Экспортируются необработанные значения (в том виде, в каком они хранятся в файле SoundFont), а не значения в физических измеримых единицах.
  Например, экспортированное время затухания будет 0,491 (секунды) или -1229 в необработанном виде.
  По умолчанию экспортируются значения в физических единицах.

```
polyphone --convert csv /path/to/file.sf2 --raw
```

При преобразовании создаётся каталог (с именем выходного файла), содержащий файл :file:`samples.csv`, а также по одному файлу на каждый инструмент и каждый пресет.
Если этот каталог уже существует, к его имени добавляется номер: ничего не заменяется, даже с -f.


## Преобразование в dls {#doc_dls}


Для этого преобразования особые параметры не используются.

```
polyphone --convert dls /path/to/file.sf2
```

Файл записывается в формате DLS уровня 2; ограничения преобразования описаны [здесь](manual/annexes/the-different-soundfont-formats.md#doc_dls).


## Рендеринг MIDI-файла {#doc_render}


### Командная строка


```
polyphone --render <MIDI/файл> <SoundFont> -d <выходной/каталог> -o <выходной/файл> -f
```


### Аргументы


--render
: Путь к воспроизводимому MIDI-файлу (расширение .mid, .midi, .kar или .rmi): MIDI-файл воспроизводится с SoundFont, а результат записывается в wav-файл.

-d, --output-dir
: Выходной каталог, в который будет записан wav-файл.
  Этот аргумент необязателен; по умолчанию используется каталог MIDI-файла.

-o, --output
: Выходной wav-файл, с расширением или без него.
  Этот аргумент необязателен; по умолчанию wav-файл получает имя MIDI-файла.

-f, --force
: Заменяет существующий wav-файл.


### Пример


```
polyphone --render /path/to/song.mid /path/to/file.sf2
```

Все каналы MIDI-файла играют SoundFont, а пресеты выбираются сообщениями смены программы из файла (банк 128 на канале 10, для ударных).
Используются настройки синтезатора: [звук](manual/settings.md#doc_sound) (реверберация, хорус, общая громкость), [полифония](manual/settings.md#doc_general) и [строй](manual/settings.md#doc_keyboard).
Результат — стереофонический wav-файл в 32-битном формате с плавающей запятой с частотой 48 000 Гц, который заканчивается, когда звук последних нот затихает.
Ноты пресета, которого нет в SoundFont, не воспроизводятся, и для этого пресета выводится предупреждение.
В графическом интерфейсе MIDI-файл также можно экспортировать из [MIDI-проигрывателя](manual/soundfont-editor/toolbar.md#doc_midi_player_settings), где каждый канал может играть свой SoundFont или пресет.


## Режим синтезатора {#doc_synth}


### Командная строка


```
polyphone --synth <файл/для/чтения> --channel <канал> --multiple-selection --key-selection <режим>
```

![Polyphone, открытый с параметром режима синтезатора](images/synth_mode.png "Polyphone, открытый с параметром режима синтезатора")


### Аргументы


-s, --synth
: Polyphone открывается в режиме синтезатора.

--channel
: Номер MIDI-канала (от 1 до 16), который прослушивается для игры.
  Значение «all» означает, что используются все каналы, обрабатываемые как один канал (значение по умолчанию).
  Значение «each» прослушивает каждый канал отдельно, что необходимо, например, для воспроизведения MIDI-выхода секвенсора (MIDI-файл также можно воспроизвести напрямую в [MIDI-проигрывателе](manual/soundfont-editor/toolbar.md#doc_midi_player)).

--multiple-selection
: Для игры можно выбрать несколько пресетов.

--key-selection
: Со значением «on» пресеты выбираются клавишами, соответствующими номеру пресета (например, клавиша 0 включает пресет 0).
  Со значением «toggle» клавиша также снимает выбор со своего пресета.

Эти аргументы необязательны, а настройки затем можно изменить в графическом интерфейсе.


### Пример


```
polyphone --synth /path/to/file.sf2 --channel 1 --multiple-selection --key-selection toggle
```


## Сервер MCP {#doc_mcp}


### Командная строка


```
polyphone --mcp <файлы/для/открытия> --mcp-port <порт>
```


### Аргументы


--mcp
: Сервер MCP, позволяющий ИИ-ассистенту просматривать, редактировать и анализировать открытые SoundFont, запускается для этого сеанса, даже если он отключён в [настройках](manual/settings.md).
  Адрес сервера выводится в консоль.
  Открывается новый экземпляр Polyphone, даже если Polyphone уже открыт.

--mcp-port
: Порт сервера MCP (этот аргумент подразумевает --mcp).
  Этот аргумент необязателен; по умолчанию используется порт из настроек (8642).

Изменение настроек сервера MCP в графическом интерфейсе заменяет эти параметры.


### Пример


```
polyphone --mcp-port 8700 /path/to/file.sf2
```


## Другие параметры {#doc_other}


-h, --help
: Выводит список всех параметров.

-v, --version
: Выводит версию Polyphone.

-r, --reset-config
: Сбрасывает конфигурацию Polyphone (настройки, геометрия окон, история и т. д.).
  Это может быть полезно при возникновении проблем.

```
polyphone --reset-config
```


## Сообщения и коды возврата {#doc_exit}


Ход загрузки и записи выводится в консоль, а ошибки записываются в поток ошибок.
Сообщения и справка выводятся на языке, выбранном в [настройках](manual/settings.md).

Код возврата:

0
: Успех.

1
: Входной файл или выходной каталог не существует, либо выходной файл уже существует (без -f).

2
: Аргументы недопустимы: неизвестный параметр, неверное значение, параметр не используется в выбранном режиме, неподдерживаемый формат входного файла и т. д.

3
: Входной файл не удаётся прочитать (SoundFont, MIDI-файл).

4
: Не удаётся записать результат.

Если преобразуется несколько файлов, возвращается код первой ошибки.


## Параметры предыдущих версий {#doc_legacy}


Параметры предыдущих версий Polyphone по-прежнему поддерживаются:

-1, -2, -3, -4, -6
: Преобразование в sf2, sf3, sfz, csv и dls, как с --convert.

-5
: Рендеринг MIDI-файла, путь к которому указывается с -c.

-i
: Входной файл, который можно указать и без этого параметра.

-c
: Конфигурация из значений, разделённых символом «|»:
  
  * преобразование в sf3: качество сжатия, «0» — низкое, «1» — среднее, «2» — высокое;
  * преобразование в sfz: 3 значения, «1» или «0», для --preset-prefix, --bank-dir и --gm-sort, например «0|1|1»;
  * преобразование в csv: «raw» для --raw;
  * рендеринг MIDI-файла (-5): путь к MIDI-файлу;
  * режим синтезатора: канал («all», «each» или от 1 до 16, причём 0 равнозначен «all», а -1 — «each»), множественный выбор («on» или «off») и выбор клавишами («on», «off» или «toggle»), например «all|on|toggle».

```
polyphone -2 -i /path/to/file.sf2 -c 2
polyphone -s -i /path/to/file.sf2 -c 'all|on|toggle'
```
