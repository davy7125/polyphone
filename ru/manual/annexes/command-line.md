Polyphone можно запускать из командной строки для преобразования SoundFont в формат [sf2](#doc_sf2), [sf3](#doc_sf3), [sfz](#doc_sfz), [csv](#doc_csv) или [dls](#doc_dls). Для преобразования поддерживаются форматы файлов [sf2](manual/annexes/the-different-soundfont-formats.md#doc_sf2), [sf3](manual/annexes/the-different-soundfont-formats.md#doc_sf3), [sfz](manual/annexes/the-different-soundfont-formats.md#doc_sfz), [dls](manual/annexes/the-different-soundfont-formats.md#doc_dls), [sfArk](manual/annexes/the-different-soundfont-formats.md#doc_sfark) и [organ](manual/annexes/the-different-soundfont-formats.md#doc_organ).

[MIDI-файл можно воспроизвести](#doc_render) с SoundFont и записать в wav-файл.
Также можно указать параметр для открытия Polyphone в [режиме синтезатора](#doc_synth).

Файлы и каталоги можно передавать в качестве аргументов, чтобы открыть их в графическом интерфейсе, например :command:`polyphone file1.sf2 file2.sf3 /path/to/directory` (каталог открывается в [обозревателе SoundFont](manual/soundfont-explorer.md)).
Есть и несколько [других параметров](#doc_other) для сброса конфигурации или вывода справки.

При преобразовании ход загрузки и записи выводится в консоль.
Код возврата равен 0, если преобразование прошло успешно, и другому значению в случае ошибки (входной файл не существует, файл не удаётся прочитать или записать, для форматов sf2, sf3 и dls выходной файл уже существует и т. д.).


## Преобразование в sf2 {#doc_sf2}


### Командная строка


```
polyphone -1 -i <file/to/convert> -d <output/directory> -o <output_file_name>
```

**Примечание:** в Windows вместо :command:`polyphone` нужно указать полный путь к Polyphone, например :command:`C:/Program files/Polyphone/polyphone.exe`.


### Аргументы


-1
: Режим «1» означает «преобразовать в sf2».

-d
: Выходной каталог, в который будет преобразован входной файл.
  Этот аргумент необязателен; по умолчанию используется каталог входного файла.

-o
: Имя преобразованного файла без расширения (расширение «.sf2» добавляется автоматически).
  Этот аргумент необязателен; по умолчанию используется имя входного файла.


### Пример


```
polyphone -1 -i /path/to/file.sfArk
```


## Преобразование в sf3 {#doc_sf3}


### Командная строка


```
polyphone -2 -i <file/to/convert> -d <output/directory> -o <output_file_name> -c <configuration>
```

**Примечание:** в Windows вместо :command:`polyphone` нужно указать полный путь к Polyphone, например :command:`C:/Program files/Polyphone/polyphone.exe`.


### Аргументы


-2
: Режим «2» означает «преобразовать в sf3».

-d
: Выходной каталог, в который будет преобразован входной файл.
  Этот аргумент необязателен; по умолчанию используется каталог входного файла.

-o
: Имя преобразованного файла без расширения (расширение «.sf3» добавляется автоматически).
  Этот аргумент необязателен; по умолчанию используется имя входного файла.

-c
: Конфигурация преобразования.
  Можно указать качество сжатия: «0» — низкое, «1» — среднее, «2» — высокое.
  Этот аргумент необязателен; по умолчанию используется «1» (среднее качество).


### Пример


```
polyphone -2 -i /path/to/file.sf2 -c 2
```


## Преобразование в sfz {#doc_sfz}


### Командная строка


```
polyphone -3 -i <file/to/convert> -d <output/directory> -o <output_file_name> -c <configuration>
```

**Примечание:** в Windows вместо :command:`polyphone` нужно указать полный путь к Polyphone, например :command:`C:/Program files/Polyphone/polyphone.exe`.


### Аргументы


-3
: Режим «3» означает «преобразовать в sfz».

-d
: Выходной каталог, в который будет преобразован входной файл.
  Этот аргумент необязателен; по умолчанию используется каталог входного файла.

-o
: Имя преобразованного файла без расширения (расширение «.sfz» добавляется автоматически).
  Этот аргумент необязателен; по умолчанию используется имя входного файла.

-c
: Конфигурация преобразования из 3 значений, разделённых символом «|». Этот аргумент необязателен; по умолчанию используется «0|0|0».
  
  * Первое значение — «1», если к имени каждого пресета нужно добавить его номер в качестве префикса, иначе «0».
  * Второе значение — «1», если для каждого банка нужно создать отдельный каталог, иначе «0».
  * Третье значение — «1», если для сортировки пресетов нужно использовать классификацию General MIDI, иначе «0».


### Пример


```
polyphone -3 -i /path/to/file.sf3 -c '0|1|1'
```

При преобразовании создаётся каталог (с именем выходного файла), содержащий файлы sfz и подкаталог :file:`samples`. Если такой каталог уже существует, к его имени добавляется число.


## Преобразование в .csv {#doc_csv}


### Командная строка


```
polyphone -4 -i <file/to/convert> -d <output/directory> -o <output_file_name> -c <configuration>
```

**Примечание:** в Windows вместо :command:`polyphone` нужно указать полный путь к Polyphone, например :command:`C:/Program files/Polyphone/polyphone.exe`.


### Аргументы


-4
: Режим «4» означает «преобразовать в .csv».

-d
: Выходной каталог, в который будет преобразован входной файл.
  Этот аргумент необязателен; по умолчанию используется каталог входного файла.

-o
: Имя преобразованного файла без расширения (расширение «.csv» добавляется автоматически).
  Этот аргумент необязателен; по умолчанию используется имя входного файла.

-c
: Конфигурация преобразования.
  Параметр «raw» позволяет экспортировать сырые значения (в том виде, в каком они хранятся в файле SoundFont) вместо значений в измеримых физических единицах. Например, экспортированное время затухания будет равно 0,491 (секунды), а в сыром виде — -1229. По умолчанию экспортируются значения в физических единицах.


### Пример


```
polyphone -4 -i /path/to/file.sf2 -c 'raw'
```

При преобразовании создаётся каталог (с именем выходного файла), содержащий файл :file:`samples.csv` и по одному файлу на каждый инструмент и пресет. Если такой каталог уже существует, к его имени добавляется число.


## Рендеринг MIDI-файла {#doc_render}


### Командная строка


```
polyphone -5 -i <soundfont> -c <MIDI/file> -d <output/directory> -o <output_file_name>
```

**Примечание:** в Windows вместо :command:`polyphone` нужно указать полный путь к Polyphone, например :command:`C:/Program files/Polyphone/polyphone.exe`.


### Аргументы


-5
: Режим «5» означает «отрендерить MIDI-файл»: MIDI-файл воспроизводится с SoundFont, а результат записывается в wav-файл.

-d
: Выходной каталог, в который будет записан wav-файл.
  Этот аргумент необязателен; по умолчанию используется каталог MIDI-файла.

-o
: Имя wav-файла без расширения (расширение «.wav» добавляется автоматически).
  Этот аргумент необязателен; по умолчанию используется имя MIDI-файла.

-c
: Путь к воспроизводимому MIDI-файлу (расширение .mid, .midi, .kar или .rmi).


### Пример


```
polyphone -5 -i /path/to/file.sf2 -c /path/to/song.mid
```

Все каналы MIDI-файла играют SoundFont, а пресеты выбираются сообщениями смены программы из файла (банк 128 на канале 10, для ударных).
Используются настройки синтезатора: [звук](manual/settings.md#doc_sound) (реверберация, хорус, общая громкость), [полифония](manual/settings.md#doc_general) и [строй](manual/settings.md#doc_keyboard).
Результат — стереофонический wav-файл в 32-битном формате с плавающей запятой с частотой 48 000 Гц, который заканчивается, когда звук последних нот затихает. Существующий wav-файл заменяется.
Ноты пресета, которого нет в SoundFont, не воспроизводятся, и для этого пресета выводится предупреждение.
В графическом интерфейсе MIDI-файл также можно экспортировать из [MIDI-проигрывателя](manual/soundfont-editor/toolbar.md#doc_midi_player_settings), где каждый канал может играть свой SoundFont или пресет.

## Режим синтезатора {#doc_synth}


### Командная строка


```
polyphone -s -i <file/to/read> -c <configuration>
```

**Примечание:** в Windows вместо :command:`polyphone` нужно указать полный путь к Polyphone, например :command:`C:/Program files/Polyphone/polyphone.exe`.

![Polyphone, открытый с параметром режима синтезатора](images/synth_mode.png "Polyphone, открытый с параметром режима синтезатора")


### Аргументы


-s
: Режим «s» означает «открыть Polyphone в режиме синтезатора».

-c
: Конфигурация синтезатора из 3 значений, разделённых символом «|». Этот аргумент необязателен; по умолчанию используется «0|off|off». Затем эти параметры можно изменить в графическом интерфейсе.
  
  * Первое значение — номер MIDI-канала (от 1 до 16), который прослушивается для игры. Значение 0 или «all» означает, что используются все каналы, обрабатываемые как один канал. Значение -1 или «each» прослушивает каждый канал отдельно, что необходимо, например, для воспроизведения MIDI-выхода секвенсора (MIDI-файл также можно воспроизвести напрямую в [MIDI-проигрывателе](manual/soundfont-editor/toolbar.md#doc_midi_player)).
  * Второе значение — «off» или «on»: отключает или включает выбор нескольких пресетов для игры.
  * Третье значение — «off», «on» или «toggle»: отключает или включает выбор пресетов клавишами, соответствующими номеру пресета (например, клавиша 0 включает пресет 0).


### Пример


```
polyphone -s -i /path/to/file.sf2 -c '1|on|toggle'
```


## Другие параметры {#doc_other}


-h
: Выводит краткую справку.

-r
: Сбрасывает конфигурацию Polyphone (настройки, геометрию окна, историю и т. д.).
  Это может помочь при возникновении проблем.

```
polyphone -r
```
