## Начальный экран {#doc_home}


Первый экран Polyphone в основном состоит из 3 частей:

* [левой части](#doc_left) с историей открытых файлов и каталогов, а также с ярлыками;
* [правой части](#doc_right), посвящённой хранилищу SoundFont;
* [верхней области](#doc_top) с вкладками и меню.


![Начальный экран Polyphone](images/page_home.png "Начальный экран Polyphone")


## Левая часть {#doc_left}


### Открытие SoundFont


Открыть SoundFont можно несколькими способами:

* щелчок по :guilabel:`Открыть SoundFont` открывает обозреватель файлов, в котором можно выбрать файлы с расширением :file:`.sf2`, :file:`.sf3`, :file:`.sfArk`, :file:`.sfz`, :file:`.dls` или :file:`.organ` (различные форматы описаны [здесь](manual/annexes/the-different-soundfont-formats.md)). Можно выбрать сразу несколько файлов;
* щелчок по :guilabel:`Создать SoundFont` открывает пустой SoundFont, в котором всё нужно создавать с нуля;
* щелчок по :guilabel:`Открыть каталог` открывает [обозреватель SoundFont](manual/soundfont-explorer.md), который просматривает весь каталог и позволяет открыть нужный файл;
* двойной щелчок по SoundFont в истории открывает его снова (выбранные элементы также можно открыть клавишей :kbd:`Enter` и удалить из истории клавишей :kbd:`Del`);
* файл или каталог, перетащенный в область истории или (из любой вкладки) на [панель вкладок](#doc_top), открывается.

Когда SoundFont открыт, появляется новая вкладка с [редактором SoundFont](manual/soundfont-editor/index.md).


### Ярлыки


Внизу левой части находятся три кнопки:

* :guilabel:`Документация`: открывает веб-браузер с [документацией](documentation) Polyphone;
* :guilabel:`Форум`: открывает веб-браузер с адресом [форума](forum) Polyphone;
* :guilabel:`Настройки`: открывает [настройки](manual/settings.md) программы в новой вкладке (также доступны по :kbd:`Ctrl`+:kbd:`,`).


## Правая часть {#doc_right}


### Онлайн-хранилище


Щелчок по кнопке :guilabel:`Онлайн-хранилище` открывает вкладку с содержимым [онлайн-хранилища SoundFont](manual/online-repository.md).


### Ежедневные SoundFont


Каждый день здесь показываются 5 случайных SoundFont, чтобы побудить пользователей открывать для себя новые SoundFont.
Двойной щелчок по одному из них открывает новую вкладку с соответствующим [описанием SoundFont](manual/online-repository.md#doc_description).
Щелчок по имени автора или по атрибуту SoundFont открывает [онлайн-хранилище](manual/online-repository.md) с соответствующим фильтром.


### Поиск


Здесь можно ввести ключевое слово, чтобы найти определённые SoundFont в онлайн-хранилище; результаты показываются в [отдельной вкладке](manual/online-repository.md).


## Верхняя область {#doc_top}


### Вкладки


Вкладки позволяют быстро переключаться между:

* [начальным экраном](#doc_home) (первая вкладка — всегда открыта),
* [редактором](manual/soundfont-editor/index.md) открытого SoundFont,
* [обозревателем SoundFont](manual/soundfont-explorer.md) (по одному на каждый открытый каталог),
* [настройками](manual/settings.md) программы,
* [онлайн-хранилищем](manual/online-repository.md),
* [описанием SoundFont](manual/online-repository.md#doc_description) из онлайн-хранилища.

Переключаться между вкладками можно с помощью сочетаний клавиш или колеса мыши:

* :kbd:`Ctrl`+:kbd:`Tab`, :kbd:`Ctrl`+:kbd:`PageDown` или :kbd:`Shift`+колесо мыши вниз над панелью вкладок — переход к следующей вкладке, не считая вкладки начального экрана,
* :kbd:`Ctrl`+:kbd:`Shift`+:kbd:`Tab`, :kbd:`Ctrl`+:kbd:`PageUp` или :kbd:`Shift`+колесо мыши вверх над панелью вкладок — переход к предыдущей вкладке, не считая вкладки начального экрана,
* :kbd:`Ctrl`+:kbd:`Home` и :kbd:`Ctrl`+:kbd:`End` — переход к первой и последней вкладке, не считая вкладки начального экрана,
* :kbd:`Ctrl`+:kbd:`W` — закрытие текущей вкладки,
* :kbd:`Ctrl`+:kbd:`H` — переход на начальный экран.

Сочетание :kbd:`Ctrl`+:kbd:`F` переводит фокус в поле поиска текущей вкладки: поле поиска начального экрана, поле поиска [онлайн-хранилища](manual/online-repository.md), [строку поиска дерева](manual/soundfont-editor/tree.md#doc_search) в редакторе SoundFont или поле поиска [обозревателя SoundFont](manual/soundfont-explorer.md).
