Эти инструкции описывают сборку Polyphone в Qt Creator.
Предполагается, что на вашем компьютере уже установлены Qt Creator с фреймворком Qt, компилятор и зависимости, необходимые для сборки Polyphone (см. соответствующие страницы).


## Что понадобится


Необходимы следующие компоненты:

* компилятор C++ (VC++, Clang, GCC, …),
* Qt Creator с фреймворком (Qt 6),
* зависимости Polyphone.

Инструкции по их установке зависят от используемой операционной системы; см. соответствующие страницы документации.


## Сборка Polyphone


### Копирование исходного кода


Получите исходный код Polyphone <a href="software" target="_blank">здесь</a> или с <a href="https://github.com/davy7125/polyphone" target="_blank">GitHub</a>.


### Открытие и настройка проекта


Сначала откройте файл :file:`polyphone.pro` и отредактируйте его, чтобы при необходимости использовать прилагаемые версии :program:`rtmidi` и :program:`stk`, если ваша операционная система их не предоставляет (прилагаемая версия :program:`rtaudio` используется по умолчанию).
Раскомментируйте следующие строки, удалив «#» в их начале:

```
DEFINES += USE_LOCAL_RTMIDI
DEFINES += USE_LOCAL_STK
```

Эти изменения можно пропустить, если вы хотите использовать библиотеки, уже установленные на компьютере (убедитесь, что они есть!).
В Windows и macOS этот шаг не нужен, поскольку там всегда используются прилагаемые версии.

Запустите Qt Creator и откройте файл :file:`polyphone.pro`.


![Открытие Qt Creator](images/open-Qt-Creator.png "Открытие Qt Creator")


Затем настройте проект.

![Настройка проекта](images/configure-project.png "Настройка проекта")


### Запуск qmake и сборка проекта


Откройте меню :guilabel:`Build` и выберите пункт :guilabel:`Run qmake`.


![Запуск qmake](images/run-qmake.png "Запуск qmake")


Выполнение :command:`qmake` завершено, когда индикатор выполнения в правом нижнем углу дошёл до 100% и стал зелёным.


![qmake завершён](images/qmake-finished.png "qmake завершён")


В разделе :guilabel:`Project` в левом столбце, а затем в разделе :guilabel:`Build&Run` выберите конфигурацию сборки (предпочтительно :guilabel:`Release`).

Наконец, выберите действие :guilabel:`Build project Polyphone` в меню :guilabel:`Build`. Во время сборки проекта могут появляться предупреждения, но ошибок быть не должно.

Теперь исполняемый файл должен находиться в каталоге сборки, созданном Qt Creator (например, :file:`build-XXX` рядом с исходным кодом), в зависимости от выбора в конфигурации сборки Qt Creator:

* в Linux файл :file:`polyphone` находится в подкаталоге :file:`bin`,
* в Windows файл :file:`polyphone.exe` находится в подкаталоге :file:`release` или :file:`debug`,
* в macOS пакет :file:`Polyphone.app` находится в каталоге :file:`macos`, расположенном рядом с каталогом :file:`sources`.
