Polyphone изначально разработан с поддержкой переводов, чтобы сделать программу доступнее.
Помочь может каждый: перевод можно создать с нуля, а существующий перевод — дополнить или улучшить.
Начиная с версии 2.6, все неполные переводы были дополнены с помощью ИИ, и их стоит проверить носителям языка.


## Что понадобится


### Файл перевода


Скачайте пакет перевода для языка, на который хотите переводить, с этой [страницы](software/translations).
Если языка ещё нет в списке, запросите его через [форму обратной связи](contact) (достаточно указать нужный новый язык).
Вскоре вы получите новый пакет перевода.

Файлы перевода также доступны в репозитории <a href="https://github.com/davy7125/polyphone" target="_blank">GitHub</a> в каталоге :file:`sources` (по одному файлу :file:`polyphone_XX.ts` на язык).


### Qt Linguist


Для перевода нужна только программа :program:`Qt Linguist` — инструмент для создания файлов перевода.
Она устанавливается вместе с Qt (см. [страницы о разработке](development/index.md)), а также доступна <a href="https://github.com/thurask/Qt-Linguist/releases" target="_blank">здесь</a> для пользователей Windows или в репозиториях дистрибутивов Linux (пакет :program:`linguist-qt6` в Debian и Ubuntu, :program:`qt6-linguist` в Fedora).


## Открытие файла перевода


Распакуйте только что скачанный пакет перевода.
В нём находится файл .ts :file:`polyphone_XX.ts`, где :file:`XX` обозначает ваш язык.
Откройте :file:`polyphone_XX.ts` в :program:`Qt Linguist` — и можно начинать перевод.


## Перевод


Каждый элемент в каждом контексте нужно перевести.
Достаточно просматривать элементы один за другим и вводить перевод.
В зависимости от вашей уверенности возможны три случая.

* Если вы не знаете, как перевести, смело пропускайте элемент.
  Это не проблема: его смогут дополнить другие.
* Вы думаете, что перевод верный, но не уверены: введите свой вариант и нажмите :kbd:`Ctrl`+:kbd:`J`.
  Элемент не будет подтверждён, но перевод всё равно будет использоваться в переведённом интерфейсе.
  Так другие люди, улучшающие перевод, будут знать, что вы не были уверены.
* Вы знаете правильный перевод: введите его и нажмите :kbd:`Ctrl`+:kbd:`Enter`.
  Элемент будет подтверждён.

Перевод требует внимания (в мире, где всё создано для того, чтобы <a href="https://medium.com/thrive-global/how-technology-hijacks-peoples-minds-from-a-magician-and-google-s-design-ethicist-56d62ef5edf3" target="_blank">его захватить</a>).
Обращайте внимание на:

* пунктуацию,
* начальные и конечные пробелы,
* регистр букв (строчные / прописные),
* формы единственного и множественного числа.

И последний совет: **не торопитесь!**
И не забывайте сохранять работу с помощью :kbd:`Ctrl`+:kbd:`S`.


## Проверка своей работы


Проверить работу можно в любой момент.
В :program:`Qt Linguist` выберите :menuselection:`File --> Release As…` и создайте файл .qm для своего перевода.
Установите его, следуя инструкциям из пакета перевода (файл :file:`readme.txt`), затем откройте Polyphone.
Перейдите в [настройки](manual/settings.md#doc_interface), выберите свой перевод в списке языков и перезапустите Polyphone.
Теперь можно проверить перевод.

**Примечание:** операция :guilabel:`Release As…` может переводить только текст без диакритических знаков. Если возникает эта ошибка, откройте терминал и выполните команду :command:`lrelease polyphone_XX.ts` (подставьте свой файл).
Файл перевода :file:`polyphone_XX.qm` можно также загружать из каталога с именем :file:`translations` (в текущем каталоге или в каталоге конфигурации Polyphone), а не встраивать его в программу.


## Отправка перевода


Когда закончите (или устанете!), отправьте редактировавшийся файл .ts (не .qm!) на адрес <contact@polyphone.io>.
Пакет перевода на этой [странице](software/translations) будет обновлён.

Если вы знакомы с GitHub, можно также предложить свой файл .ts через pull request в <a href="https://github.com/davy7125/polyphone" target="_blank">репозиторий</a> (см. руководство для участников).
