MIDI-файлы содержат MIDI-сообщения, которые вместе образуют мелодию. Их можно сочетать с синтезатором, использующим SoundFont, и в этом руководстве показано, как с помощью MIDI-файла проверить звучание SoundFont.


## Немного теории


<div class="too_complicated">
<p>При игре на клавиатуре синтезатора передаются сигналы <a href="https://ru.wikipedia.org/wiki/MIDI" target="_blank">MIDI</a>, содержащие, например, сведения о сыгранных нотах и силе их нажатия (термин, обозначающий силу удара по клавише). Проще говоря, MIDI-файл содержит хронологическую запись сигналов, переданных такой клавиатурой. До этого момента никакого звука ещё не создано.</p>

<p>Чтобы из динамика раздался звук, нужен этап преобразования, и здесь в дело вступает синтезатор: он запускает звуки по принятым MIDI-сигналам. Существует несколько типов синтезаторов; здесь речь пойдёт о семплерных синтезаторах, а точнее — о синтезаторах, использующих звуковые банки в формате SoundFont.</p>

<p>MIDI-файл может управлять 16 разными каналами, что позволяет параллельно использовать 16 разных инструментов. Помимо указания, какие ноты играть, MIDI-файл содержит команды, предписывающие синтезатору использовать инструмент X из банка Y для следующих нот на канале Z. Чтобы инструменты выбирались правильно, звуковой банк, используемый синтезатором, должен соответствовать стандарту <a href="https://ru.wikipedia.org/wiki/General_MIDI" target="_blank">General MIDI</a>, который назначает определённый инструмент каждой паре номеров X и Y. Например, инструмент <strong>001</strong> в SoundFont должен быть фортепиано.</p>

<p>Итак, здесь речь пойдёт о воспроизведении MIDI-файла, управляющего синтезатором, который запускает звуки из SoundFont, соответствующего стандарту General MIDI. Дальше будет проще!</p>
</div>


## Что понадобится


Чтобы воспроизвести MIDI-файл описанным ниже способом, вам понадобятся:

- доступ в интернет,
- веб-браузер,
- MIDI-файл, например <a href="files/ff7choco.mid" download>этот</a>,
- при желании — SoundFont, который вы хотите проверить и который соответствует стандарту <a href="https://ru.wikipedia.org/wiki/General_MIDI" target="_blank">General MIDI</a> (в [хранилище](soundfonts/midi-standard/gm) есть соответствующий фильтр),
- при желании — последняя версия Polyphone, доступная на этой [странице](software).


## Воспроизведение MIDI-файла


Простой способ — использовать синтезатор <a href="https://spessasus.github.io/SpessaSynth/" target="_blank">SpessaSynth</a>, который одновременно является проигрывателем MIDI-файлов и синтезатором SoundFont. Его преимущество в том, что он работает онлайн и не требует особой установки.

Нажмите кнопку :guilabel:`Load MIDI file`, выберите свой MIDI-файл — и всё готово.

## Подключение MIDI-выхода к Polyphone


Как уже говорилось, **SpessaSynth** — это одновременно проигрыватель MIDI-файлов и синтезатор. Можно использовать только функцию проигрывателя MIDI-файлов и отправлять сигналы в Polyphone, который возьмёт на себя синтез звука. Это удобно, если SoundFont слишком велик для передачи через интернет.

Чтобы подключить SpessaSynth к Polyphone (способ проверен в Linux):

- запустите Polyphone в [режиме синтезатора](tutorials/use-polyphone-as-a-synthesizer.md) и откройте [настройки](manual/settings.md#doc_general),
- выберите «MIDI through» в качестве MIDI-входа (запомните название),
- откройте SpessaSynth в веб-браузере и откройте его настройки,
- выберите MIDI-выход «MIDI through» (то же название, что и у MIDI-входа Polyphone).

Поскольку MIDI-файл может отправлять сообщения на 16 каналов, SoundFont нужно открыть 16 раз и для каждой вкладки указать свой канал от 1 до 16. Для удобства при открытии Polyphone можно указать SoundFont, который нужно открыть, и параметр «each», чтобы сразу открыть все 16 вкладок. Команда будет, например, такой:

```
polyphone -s -i "/home/davy/Downloads/gm.sf2" -c "each|off|off"
```

Подробнее о командной строке см. на этой [странице](manual/annexes/command-line.md#doc_synth).
