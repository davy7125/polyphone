Polyphone — не только редактор SoundFont, но и полноценный синтезатор, на котором можно играть с MIDI-клавиатуры.
В этом руководстве показано, как запустить Polyphone в режиме синтезатора.


## Что понадобится

Прежде всего нужна **мастер-клавиатура** или другой MIDI-контроллер, подключаемый к компьютеру через **адаптер MIDI-USB**.

Скачайте последнюю версию Polyphone [здесь](software), установите и откройте программу. В [настройках](manual/settings.md#doc_general) среди MIDI-входов должно быть ваше MIDI-устройство. Если его нет, скорее всего, на компьютере не установлен драйвер MIDI-адаптера (устраните это, прежде чем продолжать).

Там же, в настройках, проверьте, что вывод звука настроен правильно.

## Запуск Polyphone в режиме синтезатора


### Windows

Создайте ярлык для :file:`polyphone.exe` с аргументом :command:`-s`, как описано ниже в разделе [Параметры запуска Polyphone](#doc_launch).

### Linux

Откройте терминал и введите следующую командную строку:

```
polyphone -s
```

### Mac

Откройте терминал и введите следующую командную строку:

```
/Applications/Polyphone.app/Contents/MacOS/Polyphone -s
```

**Примечание:** если вы переместили приложение Polyphone в папку, отличную от :file:`Applications`, путь выше нужно изменить.


## Игра на инструменте


Чтобы сыграть на инструменте, просто откройте SoundFont — например, скачанный из [хранилища](soundfonts) — и выберите один из содержащихся в нём инструментов. Инструменты упорядочены по банкам: выберите банк, чтобы ниже отобразился список инструментов.

![Polyphone, открытый с параметром режима синтезатора](images/synth_mode.png "Polyphone, открытый с параметром режима синтезатора")

После выбора инструмента его диапазон клавиш отображается на виртуальной клавиатуре, и на нём можно играть соответствующими клавишами MIDI-контроллера.
Кнопка :guilabel:`MIDI-паника` останавливает все звучащие звуки (полезно, если нота «зависла»), а кнопка :guilabel:`Рекордер` открывает [рекордер](manual/soundfont-editor/toolbar.md#doc_recorder).


## Параметры


### Игра на нескольких инструментах одновременно

Чтобы при нажатии клавиши звучало несколько инструментов, просто установите параметр :guilabel:`Множественный выбор` в положение :guilabel:`вкл`. Теперь в списке инструментов можно выбрать несколько инструментов.

### Игра на нескольких инструментах по отдельности

Если к компьютеру подключено несколько MIDI-контроллеров, можно открыть несколько SoundFont и выбрать для каждого из них свой канал. Так, например, на одной клавиатуре можно играть одним инструментом, а на второй — другим. Один и тот же SoundFont можно открыть несколько раз, чтобы одновременно играть несколькими его инструментами.

Канал назначается изменением значения :guilabel:`Канал`. Например, первая открытая вкладка будет прослушивать канал 1, а вторая — канал 2.
Значение :guilabel:`все` (по умолчанию) прослушивает все каналы, а значение :guilabel:`обнаружить...` выбирает канал следующей клавиши, нажатой на клавиатуре.

![Настройка синтезатора на 2 канала](images/synth_2_channels.png "Настройка синтезатора на 2 канала")

**Примечание:** некоторые клавиатуры можно разделить на две части, чтобы одна клавиатура отправляла ноты на 2 разных канала.

### Смена инструмента клавишей

Обычно инструмент меняется MIDI-сообщением типа «Program change», и Polyphone умеет его обрабатывать.

Однако можно использовать и другой механизм: клавиши, запрограммированные на отправку сообщений «Note ON» / «Note OFF» с номером ноты, соответствующим номеру инструмента. Этот механизм удобен, если SoundFont содержит немного инструментов и клавиши можно запрограммировать на отправку определённых нот (например, пэды мастер-клавиатуры).

Если параметр :guilabel:`Выбор по клавишам` установлен в положение :guilabel:`вкл`:

* инструмент включается при получении MIDI-сообщения «Note ON»,
* инструмент выключается при получении MIDI-сообщения «Note OFF».

Этот параметр подходит, когда пэд мастер-клавиатуры настроен как переключатель (одно нажатие включает ноту, следующее — выключает).

Если выбрано :guilabel:`переключить`:

* инструмент включается при получении MIDI-сообщения «Note ON»,
* инструмент выключается при получении следующего MIDI-сообщения «Note ON».

В этом случае переключение выполняется на стороне Polyphone.


## Параметры запуска Polyphone {#doc_launch}


Все описанные выше параметры можно задать при открытии Polyphone, добавив их в командную строку. Можно также указать SoundFont, который нужно открыть.

В **Linux** или **macOS** просто дополните командную строку. В **Windows** создайте ярлык: щёлкните правой кнопкой мыши по исполняемому файлу :file:`polyphone.exe` и выберите :guilabel:`Отправить` → :guilabel:`Рабочий стол (создать ярлык)` (в Windows 11 — через :guilabel:`Показать дополнительные параметры` в контекстном меню). Затем в свойствах этого ярлыка можно добавить параметры к объекту, например:

```
"C:\Program Files\Polyphone\polyphone.exe" -s -c "all|on|toggle"
```

Все параметры описаны на этой [странице](manual/annexes/command-line.md#doc_synth).
