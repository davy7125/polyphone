The online soundfont repository can be accessed directly in Polyphone, making it possible to download, test and possibly re-use soundfonts.


## Access to the repository {#doc_access}


To open the online repository, click on :guilabel:`Online repository` or write a keyword in the search field of the [home screen](manual/index.md) and press :kbd:`Enter`.
Once the online repository is open in a new tab, the list of soundfonts available for download is displayed and it is possible to search, sort and filter the results.
The results are displayed 25 per page, and buttons at the bottom allow going to the previous or to the next page.


![Online repository](images/online_repository.png "Online repository")


### Searching a soundfont


For searching a soundfont, write a text in the top bar: the list is updated while typing and only displays the soundfonts whose title contains this text.
It is possible to write :command:`Author:"someone"` to search the soundfonts of a specific author (the exact name of the author must be written between the double quotes).
This can be combined with a text to search in the title, for instance :command:`piano Author:"someone"`.


### Sorting the results


Next to the search bar, a drop-down menu provides 4 ways to sort soundfont results:

Date
: Newest soundfonts are first (default choice).

Downloads
: Most downloaded soundfonts are first.

Rating score
: Highest rated soundfonts are first.

Title (A→Z)
: Soundfont results are sorted in alphabetical order.


### Filtering the results


Results can be filtered in different ways, several values being selectable for each filter. The button :guilabel:`Reset` cancels all filters.

Category
: Kind of instrument.

License
: It is possible to list soundfonts having a license that allows commercial use and / or sharing after the soundfont is edited.

Sample source
: Origin of the samples.

Genre
: Genre targeted by the soundfont.

MIDI standard
: Only soundfonts compliant with a [MIDI standard](manual/annexes/midi-standards.md) can be listed.

Tags
: Show soundfonts having a specific tag.


## Soundfont description {#doc_description}


A soundfont description can be opened with a double-click (or with :kbd:`Enter`) on a cell in the :guilabel:`Daily soundfonts` of the [home screen](manual/index.md#doc_right) or in the [soundfont list](#doc_access).
A [Premium account](premium) is required for soundfonts that are not in the :guilabel:`Daily soundfonts`.
Polyphone can be connected to your account in the [settings](manual/settings.md#doc_repository) of the software.


![Description page of a soundfont](images/online_repository_description.png "Description page of a soundfont")


The description of a soundfont is made of:

* a **header**, in which you can find the title, the number of comments, the number of downloads and the rating,
* a **left part**, comprising the author name, a date, the license type (please pay attention to it), the category and other attributes that characterize the soundfont,
* a **central part**, displaying a textual description, the list of files to download and possible comments.


## Download {#doc_download}


For downloading a file, click on the icon :guilabel:`download` next to its file name in the section :guilabel:`Downloads`.
You will see the download progress in a menu next to the [main menu](manual/menu.md), at the top right corner of the software.
The files are saved in the download directory defined in the [settings](manual/settings.md#doc_repository).
Once a file is downloaded and if the file is a soundfont, it is possible to open it in a [soundfont editor](manual/soundfont-editor/index.md) by clicking on the icon :guilabel:`open`.

It is possible from the menu to clear the completed downloads.
If everything is cleared, the download menu disappears.
