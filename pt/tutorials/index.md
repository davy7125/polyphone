### [Criar uma soundfont do zero](tutorials/create-a-soundfont-from-scratch.md)

Aprenda o básico para criar uma nova soundfont.

### [Como preparar uma amostra](tutorials/how-to-prepare-a-sample.md)

Um instrumento construído em uma soundfont é composto de amostras, vindas por exemplo de gravações de um instrumento real.
Este tutorial descreve como adicionar e preparar uma amostra em uma soundfont.

### [Releases personalizados](tutorials/using-custom-releases-in-an-instrument.md)

O objetivo deste tutorial é criar instrumentos expressivos usando amostras com loop cujos releases foram gravados.
Você vai aprender a aproveitar plenamente as possibilidades de uma amostra desse tipo, usando o ataque e o sustain da amostra, mas também o seu release.

### [Usar o Polyphone como sintetizador](tutorials/use-polyphone-as-a-synthesizer.md)

O Polyphone não é apenas um editor de soundfonts, é também um sintetizador completo que permite tocar com um teclado MIDI.
Este tutorial mostra como iniciar o Polyphone em modo sintetizador.

### [Criar um sintetizador com um Raspberry Pi](tutorials/create-a-synthesizer-with-raspberry-pi.md)

Um Raspberry Pi é um computador do tamanho de um cartão de crédito no qual o Polyphone pode ser instalado. Integrando-o a uma caixa com alto-falantes e associando-o a um teclado controlador, é possível criar um verdadeiro sintetizador!

### [Ler um arquivo MIDI com uma soundfont](tutorials/read-midi-file-with-soundfont.md)

Os arquivos MIDI contêm mensagens MIDI que, juntas, formam uma melodia. Eles podem ser combinados com um sintetizador que usa uma soundfont, e este tutorial mostra como usar um arquivo MIDI para testar o resultado sonoro de uma soundfont.
