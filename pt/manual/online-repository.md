O repositório online de soundfonts pode ser acessado diretamente no Polyphone, o que permite baixar, testar e eventualmente reutilizar soundfonts.


## Acesso ao repositório {#doc_access}


Para abrir o repositório online, clique em :guilabel:`Repositório online` ou digite uma palavra-chave no campo de pesquisa da [tela inicial](manual/index.md) e pressione :kbd:`Enter`.
Depois que o repositório online é aberto em uma nova aba, a lista de soundfonts disponíveis para download é exibida, e é possível pesquisar, ordenar e filtrar os resultados.
Os resultados são exibidos 25 por página, e botões na parte inferior permitem ir para a página anterior ou para a próxima.


![Repositório online](images/online_repository.png "Repositório online")


### Pesquisar uma soundfont


Para pesquisar uma soundfont, digite um texto na barra superior: a lista é atualizada durante a digitação e exibe apenas as soundfonts cujo título contém esse texto.
É possível escrever :command:`Author:"someone"` para pesquisar as soundfonts de um autor específico (o nome exato do autor deve ser escrito entre as aspas).
Isso pode ser combinado com um texto a pesquisar no título, por exemplo :command:`piano Author:"someone"`.


### Ordenar os resultados


Ao lado da barra de pesquisa, um menu suspenso oferece 4 maneiras de ordenar os resultados:

Data
: As soundfonts mais recentes aparecem primeiro (escolha padrão).

Downloads
: As soundfonts mais baixadas aparecem primeiro.

Avaliação
: As soundfonts mais bem avaliadas aparecem primeiro.

Título (A→Z)
: Os resultados são ordenados em ordem alfabética.


### Filtrar os resultados


Os resultados podem ser filtrados de diferentes maneiras, sendo possível selecionar vários valores em cada filtro. O botão :guilabel:`Redefinir` cancela todos os filtros.

Categoria
: Tipo de instrumento.

Licença
: É possível listar as soundfonts com uma licença que permita o uso comercial e / ou o compartilhamento depois que a soundfont for editada.

Origem das amostras
: Origem das amostras.

Gênero
: Gênero musical visado pela soundfont.

Padrão MIDI
: Somente as soundfonts compatíveis com um [padrão MIDI](manual/annexes/midi-standards.md) podem ser listadas.

Tags
: Mostra as soundfonts que têm uma tag específica.


## Descrição de uma soundfont {#doc_description}


A descrição de uma soundfont pode ser aberta com um clique duplo (ou com :kbd:`Enter`) em uma célula das :guilabel:`Soundfonts do dia` da [tela inicial](manual/index.md#doc_right) ou na [lista de soundfonts](#doc_access).
É necessária uma [conta Premium](premium) para as soundfonts que não estão nas :guilabel:`Soundfonts do dia`.
O Polyphone pode ser conectado à sua conta nas [configurações](manual/settings.md#doc_repository) do software.


![Página de descrição de uma soundfont](images/online_repository_description.png "Página de descrição de uma soundfont")


A descrição de uma soundfont é composta de:

* um **cabeçalho**, onde estão o título, o número de comentários, o número de downloads e a avaliação,
* uma **parte esquerda**, com o nome do autor, uma data, o tipo de licença (preste atenção a ele), a categoria e outros atributos que caracterizam a soundfont,
* uma **parte central**, que exibe uma descrição textual, a lista de arquivos para download e eventuais comentários.


## Download {#doc_download}


Para baixar um arquivo, clique no ícone :guilabel:`baixar` ao lado do nome do arquivo na seção :guilabel:`Downloads`.
O andamento do download aparece em um menu ao lado do [menu principal](manual/menu.md), no canto superior direito do software.
Os arquivos são salvos no diretório de downloads definido nas [configurações](manual/settings.md#doc_repository).
Depois que um arquivo é baixado, se ele for uma soundfont, é possível abri-lo em um [editor de soundfonts](manual/soundfont-editor/index.md) clicando no ícone :guilabel:`abrir`.

É possível limpar os downloads concluídos a partir do menu.
Se tudo for limpo, o menu de downloads desaparece.


![Baixar soundfonts](images/online_repository_download.png "Baixar soundfonts")
