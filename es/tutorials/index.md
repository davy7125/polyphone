### [Crear un soundfont desde cero](tutorials/create-a-soundfont-from-scratch.md)

Aprende lo básico para crear un nuevo soundfont.

### [Cómo preparar una muestra](tutorials/how-to-prepare-a-sample.md)

Un instrumento construido en un soundfont se compone de muestras, procedentes, por ejemplo, de grabaciones de un instrumento real.
Este tutorial describe cómo añadir y preparar una muestra en un soundfont.

### [Releases personalizados](tutorials/using-custom-releases-in-an-instrument.md)

El objetivo de este tutorial es crear instrumentos expresivos con muestras en bucle cuyos releases se han grabado.
Aprenderás a aprovechar al máximo las posibilidades de una muestra así, usando el ataque y el sostenido de la muestra, pero también su release.

### [Usar Polyphone como sintetizador](tutorials/use-polyphone-as-a-synthesizer.md)

Polyphone no es solo un editor de soundfonts: también es un sintetizador completo que te permite tocar con un teclado MIDI.
Este tutorial te muestra cómo iniciar Polyphone en modo sintetizador.

### [Crear un sintetizador con una Raspberry Pi](tutorials/create-a-synthesizer-with-raspberry-pi.md)

Una Raspberry Pi es un ordenador del tamaño de una tarjeta de crédito en el que se puede instalar Polyphone. Integrándola en una caja con altavoces y asociándola a un teclado maestro, ¡se puede crear un auténtico sintetizador!

### [Leer un archivo MIDI con un soundfont](tutorials/read-midi-file-with-soundfont.md)

Los archivos MIDI contienen mensajes MIDI que, juntos, forman una melodía. Se pueden combinar con un sintetizador que use un soundfont, y este tutorial muestra cómo usar un archivo MIDI para probar el resultado sonoro de un soundfont.
