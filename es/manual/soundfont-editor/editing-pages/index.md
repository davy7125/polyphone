Cuando se abre un soundfont, el [árbol](manual/soundfont-editor/tree.md) se llena con el contenido del soundfont.
Los editores aparecen a la derecha del árbol cuando se seleccionan elementos:

* al seleccionar el encabezado :guilabel:`General` se muestra el editor de la [información general](manual/soundfont-editor/editing-pages/editing-of-the-general-information.md),
* al seleccionar una o varias **muestras** se muestra el [editor de muestras](manual/soundfont-editor/editing-pages/sample-editor.md),
* al seleccionar **instrumentos** o **divisiones de instrumento** se muestra el [editor de instrumentos](manual/soundfont-editor/editing-pages/instrument-editor.md),
* al seleccionar **conjuntos** o **divisiones de conjunto** se muestra el [editor de conjuntos](manual/soundfont-editor/editing-pages/preset-editor.md).
