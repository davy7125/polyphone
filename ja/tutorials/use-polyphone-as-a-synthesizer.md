PolyphoneはSoundFontエディターであるだけでなく、MIDIキーボードで演奏できる本格的なシンセサイザーでもあります。
このチュートリアルでは、Polyphoneをシンセモードで起動する方法を説明します。


## 前提条件

まず、**マスターキーボード**などのMIDIコントローラーが必要です。これを**MIDI-USBアダプター**でコンピューターに接続します。

Polyphoneの最新バージョンを[こちら](software)からダウンロードし、インストールして起動します。[設定](manual/settings.md#doc_general)のMIDI入力の中に、お使いのMIDIデバイスが表示されているはずです。表示されていない場合は、MIDIアダプターのドライバーがコンピューターにインストールされていない可能性があります（先に進む前に解決してください）。

同じく設定で、オーディオ出力が正しいことを確認します。

## Polyphoneをシンセモードで開く


### Windows

下の「[Polyphoneの起動オプション](#doc_launch)」のセクションで説明しているように、引数 :command:`-s` を付けた :file:`polyphone.exe` へのショートカットを作成します。

### Linux

ターミナルを開き、次のコマンドラインを入力します。

```
polyphone -s
```

### Mac

ターミナルを開き、次のコマンドラインを入力します。

```
/Applications/Polyphone.app/Contents/MacOS/Polyphone -s
```

**注意：**Polyphoneのアプリケーションを :file:`Applications` 以外のフォルダーに移動した場合は、上のパスを適宜変更する必要があります。


## インストゥルメントを演奏する


インストゥルメントを演奏するには、たとえば[リポジトリ](soundfonts)からダウンロードしたSoundFontを開き、そのSoundFontに含まれるインストゥルメントを選択するだけです。インストゥルメントはバンクごとに整理されています。バンクを選択すると、その下にインストゥルメントの一覧が表示されます。

![シンセモードのオプションで開いたPolyphone](images/synth_mode.png "シンセモードのオプションで開いたPolyphone")

インストゥルメントを選択すると、そのキー範囲が仮想キーボードに表示され、MIDIコントローラーの対応するキーで演奏できます。
:guilabel:`MIDIパニック` ボタンは現在鳴っているすべての音を止め（ノートが鳴りっぱなしになったときに便利です）、:guilabel:`レコーダー` ボタンは[レコーダー](manual/soundfont-editor/toolbar.md#doc_recorder)を開きます。


## オプション


### 複数のインストゥルメントを同時に演奏する

キーボードのキーを押したときに複数のインストゥルメントを鳴らすには、:guilabel:`複数選択` オプションを :guilabel:`オン` にするだけです。これで、インストゥルメントの一覧で複数のインストゥルメントを選択できるようになります。

### 複数のインストゥルメントを別々に演奏する

コンピューターに複数のMIDIコントローラーを接続している場合は、複数のSoundFontを開き、開いたSoundFontごとに特定のチャンネルを選べます。こうすると、たとえば1台目のキーボードで1つのインストゥルメントを、2台目のキーボードで別のインストゥルメントを演奏できます。同じSoundFontを複数回開いて、その中の複数のインストゥルメントを同時に演奏することもできます。

チャンネルの割り当ては、:guilabel:`チャンネル` の値を変更して行います。たとえば、最初に開いたタブはチャンネル1を、2番目のタブはチャンネル2を受信するようにします。
値 :guilabel:`すべて`（初期設定）ではすべてのチャンネルを受信し、値 :guilabel:`検出...` では、キーボードで次に押されたキーのチャンネルが選択されます。

![2チャンネルのシンセ設定](images/synth_2_channels.png "2チャンネルのシンセ設定")

**注意：**キーボードによっては鍵盤を2つの部分に分割でき、1台のキーボードで2つの異なるチャンネルにキーを送信できます。

### キーでインストゥルメントを切り替える

インストゥルメントの切り替えは、通常「Program change」タイプのMIDIメッセージで行われ、Polyphoneはこれを読み取ることができます。

ただし、別の仕組みも使えます。インストゥルメント番号に対応するノート番号で「Note ON」/「Note OFF」メッセージを送信するようにプログラムしたキーを使う方法です。この仕組みは、SoundFontに含まれるインストゥルメントが少なく、キーに特定のノートを送信させるようプログラムできる場合（マスターキーボードのパッドなど）に便利です。

:guilabel:`キーによる選択` オプションが :guilabel:`オン` の場合：

* 「Note ON」MIDIメッセージを受信すると、インストゥルメントが有効になります。
* 「Note OFF」MIDIメッセージを受信すると、インストゥルメントが無効になります。

このオプションは、マスターキーボードのパッドがトグル動作（1回押すとノートが有効になり、もう1回押すと無効になる）に設定されている場合に使えます。

:guilabel:`切り替え` を選択した場合：

* 「Note ON」MIDIメッセージを受信すると、インストゥルメントが有効になります。
* もう一度「Note ON」MIDIメッセージを受信すると、インストゥルメントが無効になります。

この場合、切り替えはPolyphone側で行われます。


## Polyphoneの起動オプション {#doc_launch}


上で紹介したすべてのオプションは、コマンドラインにパラメーターを追加することで、Polyphoneを開くときに指定できます。開くSoundFontを指定することもできます。

**Linux**または**macOS**では、コマンドラインに追記するだけです。**Windows**では、実行ファイル :file:`polyphone.exe` を右クリックし、:guilabel:`送る` → :guilabel:`デスクトップ (ショートカットを作成)` を選んでショートカットを作成します（Windows 11では、コンテキストメニューの :guilabel:`その他のオプションを確認` から選びます）。次に、このショートカットのプロパティを表示すると、リンク先にパラメーターを追加できます。たとえば次のようになります。

```
"C:\Program Files\Polyphone\polyphone.exe" -s -c "all|on|toggle"
```

各オプションについては、この[ページ](manual/annexes/command-line.md#doc_synth)で説明しています。
