[ツリー](manual/soundfont-editor/tree.md)でインストゥルメントまたはそのディビジョンを選択すると、[ツールメニュー](manual/soundfont-editor/tools/index.md)には次の4つのカテゴリに分類されたツールが表示されます。

* [分析](#doc_cat_analyze)
* [高速編集](#doc_cat_fast)
* [モジュレーター](#doc_cat_mod)
* [変換](#doc_cat_transformation)

コードやミクスチャーの作成、パラメーターの表示を除き、複数選択すれば複数のインストゥルメントに対して同時にツールを使えます。


## 分析 {#doc_cat_analyze} 


### パラメータ表示 {#doc_display}


このツールは、パラメーターがキーに応じてどのように変化するかを表示します。
凡例では、グローバルディビジョンで定義された値、各ディビジョンで定義された値、パラメーターのデフォルト値が区別されます。
対数スケールも使えます（0以下の値には注意してください！）。


![パラメータ表示ツール](images/tool_display_parameters.png "パラメータ表示ツール")


## 高速編集 {#doc_cat_fast}


### アッテネーションを変更 {#doc_attenuation}


このツールは、選択したすべてのインストゥルメントのアッテネーションの最小値と最大値を計算し、上限と下限を超えない範囲で、すべてのアッテネーション値にオフセットを加えられるようにします。

たとえば、選択したインストゥルメントのディビジョンのうち最も小さいアッテネーションが16 dBで、（全体の音量を上げるために）最小アッテネーションを5 dBにしたい場合、すべてのインストゥルメントのすべてのディビジョンのアッテネーションを11 dB下げることができます。


![アッテネーション変更ツール](images/tool_change_attenuation.png "アッテネーション変更ツール")


### デチューン {#doc_detune}


この機能はインストゥルメントのノートをわずかにデチューンし、正しくチューニングされたインストゥルメントと組み合わせたときに、うねるような効果を生み出します。
効果の強さは1秒あたりのうなりの数で表され、次の項目を調整できます。

* キー60（鍵盤中央の「C」）での1秒あたりのうなりの数（この数値の符号でデチューンの方向が決まります）
* ノートに応じたうなりの数の変化：オクターブごとに、うなりの数を一定の係数で割るか掛けます（値「1」の場合、うなりの数は鍵盤全体で一定になります）。


![デチューンツール](images/tool_detune.png "デチューンツール")


<a href="files/celeste_tuning_off.mp3" download>チューニングされた</a>インストゥルメントの例です。

![](files/celeste_tuning_off.mp3)

このインストゥルメントを、<a href="files/celeste_tuning_on.mp3" download>デチューン</a>した自分自身と組み合わせたものです。

![](files/celeste_tuning_on.mp3)

対応する.sf2ファイルは<a href="files/celeste_tuning.sf2" download>こちら</a>からダウンロードできます。


### キーベース設定 {#doc_global}


このツールを使うと、各ディビジョンのキー範囲に応じて、インストゥルメントのすべてのディビジョンのパラメーターをまとめて編集できます。


![キーベース設定ツール](images/tool_keybased_configuration.png "キーベース設定ツール")


グラフは変更の強さを表します。左端の最初の値はキー0を含むディビジョンに適用される変更に、右端の最後の値はキー127を含むディビジョンに適用される変更に対応します。
グラフの最小値と最大値は調整できます。
パターンを変更すると、カーブを編集できます。

手動
: マウスでカーブを描きます。

線形昇順 / 線形降順
: カーブは直線になります。

指数関数的昇順 / 指数関数的降順
: カーブは指数関数になり、その曲がり具合はパラメーター :guilabel:`硬さ` で決まります。

ランダム
: パラメーター :guilabel:`分布` に従って、値がランダムに生成されます。

線形または指数関数の法則を使う場合、グラフを左クリックすると線形または指数関数の領域の開始点が、右クリックすると終了点が決まります。

変更するパラメーターは :guilabel:`パラメータ` で、変更の種類は :guilabel:`変更` で選びます。

加算
: 変更値を、選択したパラメーターの値に加えます。

乗算
: 変更値を、選択したパラメーターの値に掛けます。

置換
: 変更値で、選択したパラメーターの値を置き換えます。

ベロシティ範囲が特定の範囲内にあるディビジョンだけに変更を適用することもできます。たとえば、ピアノに複数のベロシティレイヤーがある場合に便利です。


### 自然なリリース {#doc_release}


このツールは、インストゥルメントの各ディビジョンにリリースを作成します。
リリース時間は、最初の2つのパラメーター（キー36でのリリース時間と、隣り合うオクターブ間の係数 :guilabel:`次のオクターブへの除数`）をもとに計算され、3つ目のパラメーター（:guilabel:`デチューン量`）でピッチの変化を加えることもできます。


![自然なリリースツール](images/tool_natural_release.png "自然なリリースツール")


### サンプル自動配置 {#doc_position}


ソフトウェアがインストゥルメントのすべてのディビジョンのキー範囲を決定し、鍵盤全体で最適に使われるようにします。
この処理は、ルートキーの異なる複数のサンプルを空のインストゥルメントにバインドしたときにも自動的に行われます。


### サウンド空間化 {#doc_spatialization}


この機能は、音の高さに応じて音を空間に配置します。たとえばピアノで便利です（低音から高音を左から右に配置）。


![サウンド空間化ツール](images/tool_sound_spatialization.png "サウンド空間化ツール")


グラフの各バーは1本の弦またはパイプを表し、その長さは音の高さに関係しています。
最も短いバーは最も高い音に、最も長いバーは最も低い音に対応します。

各ノートは空間内に配置され、左端は左から聞こえる音、右端は右から聞こえる音に対応します。
次のパターンを選べます。

昇順
: 高音が左側、低音が右側に配置されます。

降順
: 低音が左側、高音が右側に配置されます。

ホロウ
: 低音が両端に、高音が中央に配置されます。

スパイク
: 高音が両端に、低音が中央に配置されます。

ランダム
: 高音と低音がランダムに配置されます。

その他のオプションもあります。

* パターンの繰り返し回数（:guilabel:`分割数`）
* 効果の強さ（:guilabel:`広がり`）
* ディビジョンの埋め具合（:guilabel:`フィル`）
* 広がりが100%でない場合の左右のずれ（:guilabel:`オフセット`）
* :guilabel:`反転`

設定を変更するたびにグラフが更新されるので、結果を確認しやすくなっています。
マウスを重ねると、ノート番号とパンの対応が表示されます。


### トランスポーズ {#doc_transpose}


トランスポーズツールを使うと、インストゥルメント全体を移調できます。
インストゥルメントの音は同じままで、鍵盤上の位置が変わります。

入力として、半音単位のシフト量が必要です。
音を高くするには、シフト量を正の値にします。
逆に、音を低くするには、シフト量を負の値にします。
ツールは、インストゥルメントの各ディビジョンについて次の操作を行います。

* ルートキーを調整する
* 小数を含む半音数で移調した場合は、ファインチューニングを変更する
* :guilabel:`キーレンジを調整` にチェックが入っている場合は、半音数に応じてキー範囲をずらす


![トランスポーズツール](images/tool_transpose_inst.png "トランスポーズツール")


## モジュレーター {#doc_cat_mod}


### デフォルトモジュレーターを上書き {#doc_default_mod}


すべてのインストゥルメントには、デフォルトモジュレーターが自動的に割り当てられています。
このツールは、それらのモジュレーターの一覧を表示し、選択したモジュレーターを上書きまたは無効化するモジュレーターを作成できます（:guilabel:`上書き` ボタンと :guilabel:`無効化` ボタン）。


![上書きツール](images/tool_default_mod.png "上書きツール")


### モジュレーターを削除 {#doc_remove_mod}


選択したすべてのインストゥルメントのすべてのモジュレーターが削除されます。
削除されたモジュレーターの数がメッセージで表示されます。

**注意：**デフォルトモジュレーターは引き続き適用されます。
デフォルトモジュレーターを無効にする唯一の方法は、「[デフォルトモジュレーターを上書き](#doc_default_mod)」ツールで上書きすることです。


## 変換 {#doc_cat_transformation}


### コードを作成 {#doc_chords}


このツールを使うと、インストゥルメントをもとに、考えられるすべてのコード（和音）を作成できます。
たとえば、クワイアやパッドを作るときに役立ちます。

コードは、含める音（ルート、サード、フィフス、セブンス、ナインス）とその種類（メジャー、マイナー、完全、ディミニッシュ、オーギュメント）、転回の数、オクターブを選んで定義します。
コードを含むサンプルは、全てのキー、3キーごと、または6キーごとに作成され、自動ループを付けるかどうか、モノラルかステレオかも選べます。

### ディビジョンの複製 {#doc_division}


この操作は、インストゥルメントのすべてのディビジョンを複製します。
たとえば、インストゥルメントにリンクされたサンプルのキー範囲が36-38の場合、ソフトウェアはこのディビジョンを複製して、そのサンプルがキー範囲36-36、37-37、38-38に割り当てられるようにします。
これにより、同じパラメーターでディビジョン全体を編集するのではなく、ノートごとにサンプルのパラメーターを細かく編集できるようになります。

ベロシティ範囲に応じてディビジョンを複製することもできます。
サンプルを含まないインストゥルメントには、このツールは使えません。


![ディビジョン複製ツール](images/tool_division_duplication.png "ディビジョン複製ツール")


### ミクスチャー作成 {#doc_mixture}


オルガン専用のツールで、既存のインストゥルメントからミクスチャーを作成できます。
ミクスチャーの各ディビジョンと、それぞれのランクの一覧を指定するための画面が表示されます。
指定できるランクの種類は非常に豊富で、オクターブから第27倍音まであります。


![ミクスチャー作成ツール](images/tool_mixture.png "ミクスチャー作成ツール")


このツールは、選択したインストゥルメントに関連付けられたすべてのサンプル、各サンプルに定義された範囲、対応するアッテネーションをもとに動作します。
サンプルは、インストゥルメントの定義とは関係なく（[サンプルエディター](manual/soundfont-editor/editing-pages/sample-editor.md)で）チューニングされている必要があります。また、指定するルートキーには、どのストップに属するかを反映させてはいけません（たとえば、音が4'のプリンシパルであっても移調しません）。

作成したサンプルに自動ループを付けるオプションと、サンプルの作成間隔（全てのキー、3キーごと、6キーごと）を設定するオプションがあります。
最後に、作成する音の種類（モノラルまたはステレオ）を選べます。
