## テーブル {#doc_table}


### 概要


テーブルでは、インストゥルメントの設定を一覧し、編集できます。
:guilabel:`グローバル` ディビジョンでパラメーターを変更すると、すべてのディビジョンに適用されます。ただし、同じパラメーターがすでに指定されているディビジョン（ローカルでの上書き）は除きます。

斜体で表示されている行（:guilabel:`サンプルルートキー`、:guilabel:`サンプル長`、:guilabel:`ループ`）は編集できません。これらは、各ディビジョンにリンクされたサンプルのプロパティを参考として示しているだけです。

編集できるパラメーターは次のとおりです。

キー範囲
: サンプルが鳴るキーの範囲です。

ベロシティ範囲
: サンプルが鳴るベロシティの範囲です。
  同じノートでもベロシティ範囲ごとに異なる音を設定できるため、たとえばピアノの鍵盤の強弱のニュアンスを表現し分けることができます。

アッテネーション (dB)
: サンプルに適用する減衰量（デシベル）です。\
  注意：sf2形式ではインストゥルメントレベルでこの値を負にできないため、増幅はできません。

パン
: 音に適用するバランスで、ステレオで左右どちらに聞こえるかを決めます。

ループ再生
: ![ループオフ](images/loop_off.png "ループオフ"){.inline} は、ループせずに再生される音を示します。
  ![ループオン](images/loop_on.png "ループオン"){.inline} は、連続してループする音を示します。
  ![リリース](images/sample_mode_release.png "リリース"){.inline} は、キーを離したときにサンプルの再生を開始するためのものです。音量は引き続きボリュームエンベロープで決まり、リリース時にサンプルの始まりを滑らかにするため、短いアタック（0.2 ms）が加えられます。
  ![ループオン＋リリース](images/loop_on_end.png "ループオンとリリース"){.inline} は、キーを押している間はループし、キーを離すとサンプルの残りを再生する音を示します。\
  注意：再生モード「リリース」はsf2形式で定義されていないため、FluidSynthなどの他のプレーヤーでは実装されない場合があります。
  同じ動作を実現するもう1つの方法は、各サンプルに、短い無音のループの後にリリース時に鳴らす音が続くサンプルを追加することです。
  追加したサンプルは、再生パラメーター「ループオン＋リリース」で再生されます。
  チュートリアル「[インストゥルメントでカスタムリリースを使う](tutorials/using-custom-releases-in-an-instrument.md)」をご覧ください。

ルートキー
: サンプル本来のルートキーを、通常とは異なるノートに変更できます。
  たとえば、ルートキーが50のサンプルをキー範囲 [49 — 51] で演奏すると、キー49、50、51でそれぞれ-1、0、+1半音だけ移調されます。
  その後インストゥルメントレベルでルートキーを51に上書きすると、同じサンプルはキー49、50、51でそれぞれ-2、-1、0半音だけ移調されます。

チューニング（半音とセント）
: 半音単位と、半音の100分の1単位でチューニングを調整します。
  この移調は、弾いたノートに応じた初期の移調に加算されます（たとえば、ルートキーが60のサンプルは、鍵盤で62のキーを押すと初期の移調が+2半音になります）。

チューニング（スケール）
: このパラメーターは隣り合う2つのノートの音程を変更するため、弾いたノートに応じた初期の移調に影響します。
  値が100のときは平均律のスケールを表し、あるキーから次のキーへサンプルを移調するのに100セント（半音の100分の1が100個分）が使われます。
  値が0のときはこの初期の移調が無効になり、サンプルは鍵盤上のすべてのキーで同じ高さで再生されます。

フィルター
: カットオフ周波数とレゾナンスを指定して、ローパスフィルターを適用します。

ボリュームエンベロープ
: ボリュームエンベロープと、必要に応じてノートによる変化を変更します。

モジュレーション
: モジュレーション（エンベロープ、ディレイ、周波数、ノートによる変化）と、そのピッチ、フィルター、音量への効果を設定します。

ビブラート
: ビブラート（ディレイ、周波数）と、そのピッチへの効果を設定します。

エクスクルーシブクラス
: クラス内の一連のディビジョンに0以外の同じパラメーター値を割り当てることで、1つ以上のエクスクルーシブクラスを定義できます。
  エクスクルーシブクラスを定義すると、そのクラスのいずれかのディビジョンからノートが鳴ったとき、同じクラスの他の音がすべて止まります。
  エクスクルーシブクラスの有効範囲は、そのクラスが定義されているプリセットです（2つのインストゥルメントが同じプリセットにあれば、一方のインストゥルメントで鳴らした音がもう一方のインストゥルメントの音を止めます）。
  この効果はシンバルなどの打楽器に使えます。
  要するに、あるノートを弾くと、同じグループの別のノートが自動的に止まります。

コーラスとリバーブ
: コーラスとリバーブの効果の強さを示します。
  効果はソフトウェアの[設定](manual/settings.md#doc_sound)で調整できます。

固定キーと固定ベロシティ
: ディビジョンの範囲全体で、キーとベロシティの値を固定します。

オフセット
: 再生時の音の開始位置と終了位置、およびループの開始位置と終了位置を変更します。
  オフセットの単位はサンプル（値の数）です。


### テーブルでの編集を助ける機能


テーブルでの編集を簡単かつすばやく行えるよう、次の機能が用意されています。

* マウスホイールで値を変更できます（あらかじめセルを編集モードにしておく必要があります）。
* 外部MIDIキーボード（または[仮想キーボード](manual/soundfont-editor/toolbar.md#doc_keyboard)）を使って、ルートキー、キー範囲、ベロシティ範囲を設定できます（あらかじめセルを編集モードにしておく必要があります）。
* 複数のセルを選択してから最後のセルを編集すると、すべてのセルが同時に編集されます。
* :kbd:`Del` キーと :kbd:`Backspace` キーで、選択したすべてのセルの内容を消去できます。
* ソフトウェアの[設定](manual/settings.md#doc_general)でオプションを有効にしていれば、ステレオのディビジョンを同時に編集できます。
* [設定](manual/settings.md#doc_interface)で選んだオプションに応じて、キー名を数値またはテキスト（中央のCをC3、C4、C5のいずれかとする）で表示できます。
* :kbd:`Ctrl`+:kbd:`C` / :kbd:`Ctrl`+:kbd:`V` / :kbd:`Ctrl`+:kbd:`X` で、セルのまとまり（隣接していなくてもかまいません）をコピー / 貼り付け / 切り取りできます。

使用できる[ツール](manual/soundfont-editor/tools/instrument-tools.md)もお忘れなく！
特に、[キーベース設定](manual/soundfont-editor/tools/instrument-tools.md#doc_global)を行えるツールは便利です。


### ディビジョンのミュート {#doc_solo}


テストのために、テーブル内のディビジョンをミュートしたり、1つを除いてすべてのディビジョンをミュートしたりできます。
これらのオプションは、ディビジョンの見出しを右クリックするか、[ツリー](manual/soundfont-editor/tree.md#doc_menu)のコンテキストメニューから使えます。

## 範囲エディター {#doc_range}


範囲エディターでは、キー範囲とベロシティ範囲に従って、サンプルをすばやく視覚的に配置できます。
このグラフを使うと、サンプルのない領域や意図しない重なりなど、設定上の問題も見つけやすくなります。


![範囲エディター](images/edit_range.png "範囲エディター")


各サンプルは半透明の長方形で表されるため、複数の要素の重なりを確認できます。


### 長方形の選択


長方形を左クリックすると、その長方形が選択され、他の選択はすべて解除されます。
複数の長方形が重なっている場合は、続けてクリックすると、マウスカーソルの下にある長方形が順に選択されます。
長方形をダブルクリックすると、対応する[サンプル](manual/soundfont-editor/editing-pages/sample-editor.md)（[プリセットエディター](manual/soundfont-editor/editing-pages/preset-editor.md)の場合は対応するインストゥルメント）が開きます。

次の方法で複数選択ができます。

* :kbd:`Ctrl` キーを押したまま、長方形を1つずつクリックして選択します。
* :kbd:`Shift` キーを使うと、最初にクリックした長方形から次にクリックした長方形までのすべての長方形が選択されます。


### 長方形の変更


1つ以上の長方形を選択した後、左ボタンで次の操作ができます。

* 長方形の辺をつかんでサイズを変更する
* 長方形の中央を指してドラッグし、位置を変更する

複数の長方形を選択している場合は、すべての変更が同時に行われます。
:kbd:`Esc` キーを押すと、進行中の変更を取り消せます。


### スクロールとズーム


右クリックしたままにすると、選択した点を中心にズームを変更できます。

開始点が長方形の上でなければ、左クリックしたままにするとグラフを移動できます。

中ボタンをクリックするとノートが鳴ります。キーはマウスの横方向の位置で、ベロシティは縦方向の位置で決まります。


## エンベロープエディター {#doc_envelope}


エンベロープエディターでは、ボリュームエンベロープを定義する8つのパラメーターと、モジュレーションエンベロープを定義する8つのパラメーターをグラフで確認できます。
そのため、各パラメーターの影響をよりよく理解するためのツールになります。


![エンベロープエディター](images/edit_envelope.png "エンベロープエディター")


グラフの上にあるボタンで、編集対象をボリュームエンベロープ（緑で表示）とモジュレーションエンベロープ（赤で表示）の間で切り替えます。
モジュレーションエンベロープの編集中は、ボリュームエンベロープが細い線で表示されます。

グラフの左側は、キーを**押した**ときのエンベロープの変化を表します。
この表示には、8つのパラメーターのうち7つが関係しています。

ディレイ
: キーを押した直後に、エンベロープが0のままとなる時間です。ほとんどの場合、キーを押したらすぐに音を聞きたいので、このパラメーターは0のままにします。ただし**ディレイ**は、たとえば複数のレイヤーで構成された厚みのあるパッドサウンドを作るときに役立ちます。キーを押してから0.5秒後に2つ目の音のレイヤーを加えたい場合は、このフィールドに「0.5」と入力します。ディレイは音の再生を遅らせるのではなく、音を消音します。ディレイを0.5秒に設定すると、再生開始から0.5秒後の時点のサンプルから聞こえ始め、最初の0.5秒は無音で再生されたことになります。

アタック
: **ディレイ**の後、エンベロープが0から最大値まで上昇する時間です。たとえば、バイオリンのような擦弦楽器の音はアタックがかなり長く、ギターのような撥弦楽器の音はアタックが非常に短くなります。アタックをできるだけ短くしたい場合でも、少なくとも0.001を入力することをおすすめします。そうしないと、キーを押したときに「クリック」音が聞こえることがあります。

ホールド
: **アタック**の後、エンベロープが最大値を保つ時間です。

ディケイ
: **ホールド**の後、エンベロープが最大値から**サステイン**で指定した値まで徐々に下がる時間です。**サステイン**で減衰量を指定していない場合（初期値の0 dB）、**ディケイ**の間の音量は、指定した値にかかわらず最大のままです。

サステイン
: **ディケイ**の後、押したキーを離すまで保たれる値です。**アッテネーション**と同様に、サステインの値はデシベルで表した減衰量です。ディケイ時間の後に音量を半分にしたい場合は、6 dBに設定します。音を完全に消したい場合は「144」を指定できます。

キー → ホールド
: キーに応じて**ホールド**の時間を変化させます（下記参照）。

キー → ディケイ
: キーに応じて**ディケイ**の時間を変化させます（下記参照）。

**キー → XXX** を正の値にすると、高音に向かうほどXXXの時間が徐々に短くなり、負の値にするとその逆になります。
たとえば、次のようになります。

* 値が100の場合、中央のC（60）より1オクターブ上がるごとにXXXの時間は半分になり、中央のCより1オクターブ下がるごとに2倍になります。
* 値が-100の場合、中央のC（60）より1オクターブ上がるごとにXXXの時間は2倍になり、中央のCより1オクターブ下がるごとに半分になります。

これらのパラメーターは、サステインペダルを踏んだ状態のギターやピアノを作るときに便利です。音が低いほど、音が聞こえなくなるまでの時間が長くなります。

右側は、キーを**離した**ときのエンベロープの変化を表します。
この表示に関係するのは**リリース**の時間だけです。
この時間の間に、エンベロープは徐々に0に戻ります。
バイオリンやシンセパッドの音はリリース時間が比較的長く、オルガンなどの音は非常に短くなります。実際には、リリース時間が短い場合でも、少なくとも0.2秒に設定することをおすすめします。リリース時間が短すぎると、心地よく自然な響きにならないためです（ただし、作りたいインストゥルメントのイメージにもよります）。

ツリーでインストゥルメントのディビジョンを1つだけ選択している場合は、対応する[サンプル](manual/soundfont-editor/editing-pages/sample-editor.md)の波形が背景に表示されます。
これにより、再生されるサンプルに対してエンベロープがどのように変化するかを、よりわかりやすく確認できます。


### 点の移動


曲線の各点は左ボタンで移動できます。

* **ディレイ**、**アタック**、**ホールド**、**リリース**の終点は横方向に移動します。
* **ディケイ**の終点は両方向に移動します。横方向で**ディケイ**、縦方向で**サステイン**が変わります。
* キーを離す点は縦方向に移動し、**サステイン**が変わります。

マウスカーソルの下にある点のパラメーターとその値は、グラフの上部の隅に表示されます。
複数の点が同じ位置にある場合、円はいくつかの部分に分割され、左から右へ最初の段階から最後の段階の順に並びます。

**キー → ホールド**と**キー → ディケイ**は、**ホールド**または**ディケイ**の終点を横切る小さな定規で編集します。定規の上端はディビジョンの最も高いキーの長さを、下端は最も低いキーの長さを示します。
一方の端を動かすと、そのキーの長さだけが変わり、もう一方の端はその場に留まります。:kbd:`Ctrl` キーを押したままにすると、両端が定規の中央を軸に動きます。
定規はマウスが点に近づくと表示され、パラメーターが 0 でない場合は表示されたままになります。

:kbd:`Shift` キーを押すと、より細かく調整できます。
点をグラフの右端に押し当てると、ビューがスクロールまたはズームアウトし、より長い時間を設定できます。
:kbd:`Esc` キーを押すと、進行中の変更を取り消せます。
点をダブルクリックすると、そのパラメーターがリセットされ（定規の端の場合は**キー → ホールド**または**キー → ディケイ**のみ）、:guilabel:`グローバル` ディビジョンの値またはデフォルト値が再び適用されます。

複数のディビジョンまたはインストゥルメントを選択している場合は、すべてのエンベロープが一緒に変更されます。長さは同じ比率で、その他の値は同じ量だけ変わります。


### スクロールとズーム


右クリックしたままにすると、選択した点を中心にズームを変更できます。

クリックが曲線の点の上で始まらなければ、左クリックしたままにするとグラフを移動できます。


## 音色ビュー {#doc_timbre}


音色ビューは、キーボード全体にわたって、インストゥルメントの音色を**実際に聞こえるとおりに**表示します。表示されるのは各倍音のレベルで、各サンプルをそれが鳴らすキーへ移調し、そのディビジョンのアッテネーション、フィルター、モジュレーターを適用した後の値です。
これにより、ばらつき、特にサンプル間のつなぎ目での不連続が目に見えるようになります。
このビューから、計算ノートの作成、冗長なサンプルの削除、サンプルの音色やレベルの補正を行えます。
ビューは測定と提案をするだけで、自動的に適用されるものは何もありません。


![音色ビュー](images/edit_timbre.png "音色ビュー")


### 対象となるディビジョン


ビューには、左上で選んだベロシティ（初期値は100、以降は最後に使った値）で再生される内容が表示されます。
その横のバーにはインストゥルメントのベロシティレイヤーが表示され、レイヤーをクリックすると、そのレイヤーの中央のベロシティが選択されます。

対象となるのは、このベロシティで鳴り、[ミュート](#doc_solo)されておらず、キーを離したときにだけ再生されるもの（再生モード「リリース」）ではないディビジョンです。
したがって、ノイズやリリース音などのディビジョンをビューから除外するには、そのディビジョンをミュートします。
「[選択範囲をソロ](manual/soundfont-editor/tree.md#doc_menu)」が有効な場合は、ミュートの状態が選択に合わせて変わるため、ミュートは考慮されません。
同じキーを鳴らすディビジョン（ステレオペア、レイヤー）はまとめて扱われ、それらのパワーが合算されます。

ここでいう**ルートキー**は、そのルートキーを持つすべてのディビジョンをまとめたもので、キー範囲が複数に分かれていることもあります。
サンプルはバックグラウンドで分析されます（残りのサンプル数は右上に表示されます）。倍音はループ部分で測定され、ループがない場合は音の安定した部分で測定されます。
これらの分析結果は、サンプルのデータ、ループ、ルートキー、ピッチ補正のいずれかが変わるまで保持されます。


### マップ


各列は1つのキーで、下に表示されるキーボードと位置がそろっています。各行は倍音の次数（H1：基音、H2：第2倍音…）で、スペクトログラムと同じく1次が一番下になります。
最初の次数は1つずつ表示され、それ以降の次数は帯域ごとにまとめられます（[部分音](#doc_timbre_partials)を参照）。

マップの上にある概要行には、キーごとに次の内容が表示されます。

* :guilabel:`レベル`：全体のレベル
* :guilabel:`音色`：ルートキーの、基準に対する音色の偏差（基準の信頼性が低くなるキーボードの両端では斜線で表示）
* :guilabel:`トランスポーズ`：サンプルが下に移調されている場合は青、上に移調されている場合は赤
* さらに、:guilabel:`オプション` > :guilabel:`概要行` メニューで選んだもの：:guilabel:`明るさ`（次数の重心）、:guilabel:`奇数次 / 偶数次`（奇数次と偶数次の比較）、:guilabel:`ノイズ`（倍音とノイズの比）、:guilabel:`ピッチ精度`（平均律の最も近い音からのセント数）、:guilabel:`ループ`（ループの品質）

マップでは、縦線がディビジョン間のつなぎ目を示し（サンプルが変わる箇所では太くなります）、点が各ルートキーを示します。斜線は、存在しない次数（サンプルまたは出力の帯域外、上限より上）や確実に測定できない次数を示し、何も鳴らないキーはグレーで表示されます。
ツールチップには、マウスカーソルの下にあるセルの値が表示されます。キー、次数、レベル、偏差、サンプル、トランスポーズ、持続時間の倍率です（サンプルを上に移調すると、アタック、トレモロ、うなりが速くなります）。

:guilabel:`表示` リストで、色が何を表すかを選びます。

絶対レベル
: 各次数のレベル（dB）です。

相対レベル
: そのキーで最も強い次数を基準とした各次数のレベルです。レベルに関係なく音色を表します。

基準からの偏差
: ルートキーが鳴らすすべてのキーにわたる、各次数でのルートキーとその基準との差です。強すぎる（赤）か弱すぎる（青）かを示します。

段差
: 前のキーとの差です。つなぎ目での不連続がわかります。

トランスポーズ
: キーと、そのサンプルのルートキーとの間の半音数です。

信頼度
: パワーのうち、確実に測定できた部分の割合です。

:guilabel:`オプション` メニューでは、キーボード全体を表示するかルートキーごとに1列だけを表示するか、しきい値の段階で色分けするか（許容差内の偏差は中立の色になります）、クリックしたキーを再生するかも選べます。
マップの下のキーボードでは、ビューのベロシティでインストゥルメントを演奏できます。


### 基準と判定


ルートキーの**基準**とは、隣接するルートキーから予測される値です。隣接するルートキーをそのルートキーのキーで（それぞれのディビジョンのパラメーターで）鳴らし、それらのレベルを次数ごとにdB単位で補間します。
キーボードの両端では、同じ側にある2つの隣接ルートキーから基準を外挿するため、信頼性が低くなります。
:guilabel:`局所回帰` を選ぶと、代わりに各側の複数の隣接ルートキーに対するロバスト回帰が使われ、欠陥のある隣接ルートキーの影響が小さくなります。

ルートキーとその基準との偏差は、次の2つの数値にまとめられます。

* **レベル**の偏差：全体のレベルの差で、アッテネーションで補正できます。
* **音色**の偏差：レベルの偏差を除いたうえでの各行の差の平均です。各行はその音量に応じて重み付けされます（弱い倍音も考慮されますが、支配的にはなりません）。

:guilabel:`判定` の帯は、各ルートキーと各つなぎ目に、形と色で示すラベルを付けます。

整合 ✓（緑）
: 音色の偏差が許容差内にあります。

冗長 −（青）
: ルートキーは整合しており、削除してもそのキーでの変化が :guilabel:`冗長` のしきい値未満で、新しいつなぎ目に不連続も生じません。削除できます。

要補正 ~（オレンジ）
: 音色の偏差が許容差と最大の間にあります。音色を補正できます。

差が大きすぎる ×（赤）
: 音色の偏差が最大を超えています。ルートキーを削除するか、計算ノートで置き換えられます。

不連続 +（紫）
: サンプルが切り替わる箇所で、音色の段差が :guilabel:`不連続` のしきい値を超え、2つのルートキーの間にサンプルのないキーがあります。そこに計算ノートを作成できます。

レベル ▲ ▼（黄）
: レベルの偏差が :guilabel:`レベル` のしきい値を超えています（▲ 大きすぎる、▼ 小さすぎる）。アッテネーションを補正できます。

しきい値は :guilabel:`しきい値` メニューで設定します。
初期値（:guilabel:`許容差` 4.5 dB、:guilabel:`最大` 8 dB、:guilabel:`冗長` 2.5 dB、:guilabel:`不連続` 6 dB、:guilabel:`レベル` 2.5 dB）は、ルートキーの70%で隣接ルートキーとの偏差が4.5 dB未満となるオルガンのサンプルセットから求めたものです。インストゥルメントに合わせて調整できます。
つなぎ目や偏差が意図的な場合もあります（ある楽器が別の楽器に変わる場合や、ミクスチャーの折り返しなど）。ラベルはあくまで提案です。


### 部分音 {#doc_timbre_partials}


:guilabel:`部分音` メニューでは、マップの行を設定します。この設定は、表示、偏差、補正で共通です。

個別に表示する次数
: 1つずつ表示して比較する次数の数です（初期値は10）。耳は最初のいくつかの倍音を個別に聞き分けますが、それ以降の倍音はまとめて明るさとして知覚されます。

以降の次数
: それ以降の次数は、1/3オクターブ（11-12、13-16、17-20…）または1オクターブの帯域にまとめられます。これにより、弱い高次の倍音が多数あっても、最初の次数より大きな重みを持つことはありません。

上限
: この周波数より上の部分音は無視されます（初期値は16 kHz、またはサンプルレートの半分）。

ダイナミックレンジ
: そのキーで最も強い次数よりこの値以上低い次数は比較されません（初期値は60 dB）。


### 詳細と操作


キーをクリックすると、そのキーで鳴る内容がマップの下に表示されます。各サンプルとそのトランスポーズ、アッテネーション、フィルター、持続時間の倍率、ピッチ、ルートキーの偏差、そしてルートキーを削除した場合の変化です。
棒グラフは、聞こえるレベルを基準と比較します。サンプルのないキーでは、そのキーに作成できる計算ノート（マップ上の破線の列）と比較します。

ルートキーをクリックすると、そのディビジョンが[ツリー](manual/soundfont-editor/tree.md)で選択され、逆にツリーでディビジョンを選択すると、そのルートキーが選択されます。
:kbd:`Ctrl` キーまたは :kbd:`Shift` キーを使うか、キーの上でマウスをドラッグすると、複数のルートキーを選択できます。

右側のボタンとマップのコンテキストメニューは、選択したルートキーに適用されます。

ここにノートを作成...
: サンプルのないキーで使います。最も近いルートキーを移調し、その倍音のレベルを2つ目のルートキーから補間（または外挿）します。使用するルートキーは選択でき、キーがそれらから離れている場合は警告が表示されます。周囲のキー範囲は調整され、新しいノートの範囲に完全に含まれるディビジョンは削除されます。

削除...
: ルートキーのディビジョンが削除され、そのキーは隣接ルートキーが担当します。使用されなくなったサンプルも削除できます。

計算ノートで置き換え...
: ルートキーを削除し、隣接ルートキーから作成し直します。

音色を補正...
: [補正](#doc_timbre_correction)ウィンドウを開きます。

レベルを補正
: レベルの偏差が0になるように、ディビジョンのアッテネーションを変更します（アッテネーションは負にできません）。

レンダリングで確認
: サウンドエンジンでキーを再生し、結果の倍音を測定します。測定結果は棒グラフに表示され、ビューの計算を確認できます。

これらのディビジョンをミュート
: コンテキストメニューにあります。ディビジョンをビューから除外します。

:guilabel:`提案` メニューは、ラベルの付いたすべてのルートキー（またはつなぎ目）を選択し、確認の後、対応する操作を適用します。要補正のルートキーの補正、差が大きすぎるルートキーの置き換え、冗長なルートキーの削除、不連続箇所への計算ノートの作成、ずれたレベルの補正です。
これらは最も悪いものから順に処理され、操作のたびに基準が計算し直されます。欠陥のあるルートキーは隣接ルートキーの基準も歪めるため、そのルートキーが補正されるまでは、隣接ルートキーも半分ほど欠陥があるように見えます。

それぞれの操作、または一連の操作は、1回で元に戻せます（:kbd:`Ctrl`+:kbd:`Z`）。


### 音色の補正 {#doc_timbre_correction}


![音色の補正](images/timbre_correction.png "音色の補正")


ウィンドウには、各行について、聞こえるレベル、目標、予想される結果が表示され、次のパラメーターを設定できます。

基準
: 補正の目標です。:guilabel:`隣接ルートキー間の補間`、各側の複数の隣接ルートキーに対する :guilabel:`局所回帰`、または :guilabel:`ルートキーに揃える`（別のルートキーをそのキーで鳴らしたもの）から選びます。

音色を補正 (サンプルデータ)
: 各行のゲインを、ピッチに追従する最小位相のカーブでサンプルのデータに適用します。そのため、トランスポーズの量にかかわらず、補正はディビジョンのすべてのキーで有効なままで、ループも保たれます。ステレオペアの2つのサンプルには同じ補正が適用されます。

レベルを補正 (アッテネーション)
: レベルの偏差を、ディビジョンのアッテネーションで補正します。データは変更されません。アッテネーションが負になってしまう場合は、残りの分をフルスケールの範囲内でデータに反映します。

許容差
: 行の偏差がこの値より小さい場合は補正されず、超えた分のみが補正されます。

強さ
: 偏差のうち補正する割合です。

最大補正量
: 1つの行に適用するゲインの最大値です（増幅側と減衰側のそれぞれ）。

補正する次数
: すべての行、または1次から指定した次数までの次数のみです。

明るさ、奇数次
: 目標に加える傾き（正の値で音が明るくなります）と、目標の奇数次（3、5、7…）に加えるレベルです。

:guilabel:`試聴` セクションでは、:guilabel:`再生` ボタンで元の音（A）と補正後の音（B）を比べられます。
補正によってフルスケールを超えてしまう場合は、サンプルのレベルを下げ、アッテネーションで補います。
サンプルが他のディビジョンやインストゥルメントでも使用されている場合、Polyphoneは、補正するルートキー用にサンプルを複製するか、すべての箇所で変更するかを確認します（回答はPolyphoneを閉じるまで記憶させることができます）。


## モジュレーター {#doc_modulator}


インストゥルメントの編集ページの下部は、インストゥルメント全体または特定のディビジョンに対してモジュレーターを作成するためのエリアです。
インストゥルメントを演奏すると、モジュレーターは1つまたは2つのMIDI信号を受け取り、設定された数式に従ってテーブル内のパラメーターの1つを変更します。
モジュレーターの出力を、別のモジュレーターの入力として使うこともできます（この機能は[sf2形式](manual/annexes/the-different-soundfont-formats.md#doc_sf2)のバージョン2.04で導入されたもので、一部のシンセサイザーでは対応していない場合があります）。


![モジュレーターエディター](images/modulator_editor_2.png "モジュレーターエディター")


左側のボタンは、次の操作のためのものです。

* モジュレーターエリアの展開 / 折りたたみ
* モジュレーターの追加 / 削除
* 1つ以上のモジュレーターのコピー / 貼り付け / 複製

モジュレーターを追加すると、テーブル内の対応するセルの枠線が太くなります（上の画像の :guilabel:`グローバル` 列にあるチューニングのセルを参照）。

ディビジョン（またはグローバルディビジョン）のモジュレーターは、ディビジョンを1つだけ選択している場合にのみ表示されます。
セクションを折りたたむと、モジュレーターの数と、それらが変更するパラメーターの概要が表示されます。
テーブルでセルを選択すると、対応するパラメーターに作用するモジュレーターが選択され、その逆も同様です。

各モジュレーターは、左から順に次の要素で構成されています。

ソース
: 1つ目のソースはMIDI信号です。弾いたノートのベロシティまたはキー、ポリフォニックプレッシャー、チャンネルプレッシャー、ピッチホイール、ピッチホイールの感度、MIDIコントローラー（:guilabel:`CC`）のいずれかです。
  また、このモジュレーターを出力先とする1つ以上の他のモジュレーターの出力（:guilabel:`リンク`）にすることもできます。
  2つ目のソースは省略可能で、1つ目のソースの効果を変化させます。

カーブ
: 各ソースの横にあるボタンを押すとカーブの一覧が表示され、信号の変換方法を選べます。リニア、凹型、凸型、スイッチ、増加または減少、ユニポーラ（0から1）またはバイポーラ（-1から1）があります。

量
: モジュレーションの最大振幅です。

変換
: :guilabel:`操作なし` または :guilabel:`絶対値`（モジュレーションの結果の絶対値を使用）です。

出力先
: モジュレーターが変更するパラメーター、または別のモジュレーター（:guilabel:`モジュレーター`）です。
  出力先の下のテキストはモジュレーションの範囲を示します。パラメーターに加算される値（:guilabel:`加算 下限` … :guilabel:`上限`）、またはパラメーターに掛けられる係数（:guilabel:`乗算 下限` … :guilabel:`上限`）です。

モジュレーターがリスト内のそれより上にあるモジュレーターと同一の場合は、:guilabel:`…によって上書き` と表示されます。
インストゥルメントレベルでは、:guilabel:`デフォルトモジュレーターを上書き` はsf2形式の[デフォルトモジュレーター](manual/soundfont-editor/tools/instrument-tools.md#doc_default_mod)の1つを置き換えるモジュレーターであることを示し、:guilabel:`デフォルトモジュレーターを無効化` はその量が0であること（その結果、デフォルトモジュレーターが無効になること）を示します。
