Polyphoneは、デジタルオーディオワークステーション（DAW）やその他のオーディオプラグインのホストで使えるプラグインとしても提供されています。
このプラグインは、sf2、sf3、sfz、dls形式のSoundFontをPolyphoneのシンセサイザーで演奏します。そのため、SoundFontはホストでもエディターでも同じ音で鳴ります。
プラグインはSoundFontを演奏しますが、編集はしません。変更はPolyphoneで行い、その後SoundFontをプラグインで開き直します。

プラグインは、Linux、Windows、macOSでVST3、CLAP、LV2の形式で利用でき、macOSではAudio Unit（AU）の形式でも利用できます。


![Polyphoneプラグイン](images/plugin.png "Polyphoneプラグイン")


## インストール {#doc_install}


プラグインはOSごとのアーカイブで配布されており、「[ソフトウェア](software)」セクションから入手できます。
ホストで使う形式を、ホストがプラグインを探すフォルダーにコピーしてから、ホストでプラグインを再スキャンします。

Linux
: :file:`Polyphone.vst3` を :file:`~/.vst3/` に\
  :file:`Polyphone.clap` を :file:`~/.clap/` に\
  :file:`Polyphone.lv2` を :file:`~/.lv2/` に

macOS
: :file:`Polyphone.vst3` を :file:`~/Library/Audio/Plug-Ins/VST3/` に\
  :file:`Polyphone.clap` を :file:`~/Library/Audio/Plug-Ins/CLAP/` に\
  :file:`Polyphone.component` を :file:`~/Library/Audio/Plug-Ins/Components/` に（Audio Unit形式。Logic ProとGarageBandで使われます）\
  :file:`Polyphone.lv2` を :file:`~/Library/Audio/Plug-Ins/LV2/` に

Windows
: :file:`Polyphone.vst3` を :file:`C:\Program Files\Common Files\VST3` に\
  :file:`Polyphone.clap` を :file:`C:\Program Files\Common Files\CLAP` に\
  :file:`Polyphone.lv2` を :file:`%APPDATA%\LV2` に

macOSでは、プラグインは公証（notarization）を受けていません。ホストがプラグインを読み込まない場合は、ダウンロードしたファイルの隔離フラグを削除してください。たとえば次のようにします。

```
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Polyphone.vst3
```


## SoundFont {#doc_soundfont}


ウィンドウの上部には、SoundFontの名前とパスが表示されます。
SoundFontは次の方法で開きます。

* ボタン :guilabel:`開く...` を使う
* その右の矢印を使う（最近開いた10個のSoundFontが一覧表示されます）
* ファイルをウィンドウにドロップする

sfzファイルとdlsファイルは、Polyphoneがインポートするときと同じように変換されます。sfzファイルのサンプルは、そのファイルが参照するオーディオファイルです。
SoundFontを開くと、まず構造が読み込まれます。楽器はすぐに一覧に表示され、演奏できます。
サンプルはその後バックグラウンドで読み込まれ、その間は名前の前に読み込み中のアイコンが表示されます（ツールチップに進行状況が表示されます）。サンプルがまだ読み込まれていない音は鳴りません。
演奏した音と選択した楽器のサンプルが優先して読み込まれ、sf3ファイルのサンプルは展開されます。
すべて読み込まれると、演奏中にディスクから読み込むことはありません。オフラインのエクスポートは、すべてのサンプルが読み込まれるまで待ちます。
プラグインの複数のインスタンスが同じファイルを演奏する場合（たとえばトラックごとに1つ）、ファイルの読み込みとメモリへの保持は1回だけです。
ファイルが変更された場合（たとえばPolyphoneで保存し直した後）は、再び読み込まれます。


## 演奏モード {#doc_modes}


楽器（SoundFontのプリセット）のリストの上にある3つのボタンで、楽器の演奏方法を選びます。

:guilabel:`単一楽器`
: リストで選択した楽器を、16のMIDIチャンネルすべてで演奏します。
  楽器は、バンク番号とプログラム番号付きで表示されます（たとえば「000:024 Guitar」）。

:guilabel:`16 チャンネル`
: 各MIDIチャンネルが、その行で選んだそれぞれの楽器を演奏します。
  :guilabel:`プログラムチェンジ` を選ぶと、General MIDIシンセサイザーと同じように、チャンネルが受信したバンクセレクトとプログラムチェンジのメッセージで選ばれた楽器を演奏します。このとき、チャンネル10ではドラム用にバンク128が使われます。
  演奏中の楽器は各行の右に表示されます。
  このモードは、複数の楽器用にアレンジされたMIDIファイルを演奏するのに便利です。

:guilabel:`MPE`
: 選択した楽器をMPE（MIDI Polyphonic Expression）コントローラーで演奏します。各ノートが独自のチャンネルを持つため、ピッチベンド、プレッシャー、音色（CC 74）もノートごとに独立しています。
  コントローラーが設定（RPN 6）を送ってくるまでは、15チャンネルの下位ゾーンが使われます。
  ゾーンのマスターチャンネルは、そのゾーンのすべてのノートに作用します。マスターチャンネルのピッチベンドは各ノートのピッチベンドに加算され、そのコントローラーはすべてのノートに適用されます。
  ピッチベンドの範囲は、ノートでは48半音、マスターチャンネルでは2半音で、コントローラーから変更できます（RPN 0）。


![「16 チャンネル」モードのプラグイン](images/plugin_channels.png "「16 チャンネル」モードのプラグイン")


## パラメーター {#doc_parameters}


パラメーターはPolyphoneのシンセサイザーのもので、Polyphoneの[サウンド](manual/settings.md#doc_sound)と[キーボード](manual/settings.md#doc_keyboard)の設定にも同じものがあります。
:guilabel:`ゲイン`（-24～+24 dB）はヘッダーにあり、そのほかのパラメーターは右側にまとめられています。

:guilabel:`チューニング`
: :guilabel:`基準ピッチ`：A#3からA4までの音とその周波数（A4で400～480 Hz、初期設定は440 Hz）です。この音は、音律に関係なくこの周波数で鳴ります。
  :guilabel:`トランスポーズ`：-24～+24半音です。ドラムはトランスポーズされません。

:guilabel:`ベロシティ`
: ノートのベロシティに対する応答を設定します。各設定はグラフで表示されます（左から右へベロシティ0～127）。
  
  * :guilabel:`フィルターカットオフ`：ベロシティに応じてフィルターのカットオフ周波数を最大2オクターブ下げる既定のモジュレーターで、Polyphoneの[サウンド](manual/settings.md#doc_sound)設定と同じものです。SoundFont形式のバージョン2.04（既定）では、ベロシティが小さいほど大きく下げます。バージョン2.01にはベロシティ64での段差があり、これはバージョン2.04で修正された誤りです。この段差を補うように作られた古いSoundFontのための互換モードです。:guilabel:`無効`では、カットオフ周波数はベロシティに左右されません。
  * :guilabel:`カーブ`：受信したノートのベロシティに適用するカーブです。中央でリニア（既定。ダブルクリックで戻ります）、左へ行くほど凹型（柔らかいベロシティ。高いベロシティを出すにはより強いタッチが必要です）、右へ行くほど凸型（ベロシティが素早く上がります）になります。

:guilabel:`音律と音階`
: カテゴリー別のPolyphoneの音律と音階、続いてカスタム音律で、選んだ :guilabel:`調` に移調されます。
  右側の鍵盤には各音の微調整がセント単位で表示され、Polyphoneの[キーボードの設定](manual/settings.md#doc_keyboard)と同じように編集できます（マウスホイールまたは上下のドラッグ、ダブルクリックで0に戻す、コンテキストメニューで音の使用の切り替えや調の設定）。編集した音律はカスタム音律になります。
  音階で使わない音は、:guilabel:`すべて演奏` をオンにしない限り鳴りません。

:guilabel:`リバーブ`
: :guilabel:`レベル`、:guilabel:`サイズ`、:guilabel:`幅`、:guilabel:`ダンプ`。

:guilabel:`コーラス`
: :guilabel:`レベル`、:guilabel:`デプス`、:guilabel:`周波数`。

:guilabel:`音律と音階`、:guilabel:`リバーブ`、:guilabel:`コーラス` の各グループには、タイトルの右にスイッチがあります。オフにするとグループが折りたたまれ、その音律やエフェクトは適用されません（すべての音を使う平均律、エフェクトなし）。設定は保持されます。
ウィンドウの高さは、展開されたグループに合わせて変わります。

これらのパラメーターはすべてホストでオートメーションできます。ただし、基準ピッチの音（オートメーションされるのはA4の周波数です）とカスタム音律の微調整は除きます。これらはプロジェクトと一緒に保存されます。


## キーボードとステータス {#doc_keyboard}


ウィンドウ下部のキーボードには受信したノートが表示され、マウスで演奏することもできます。
その下には、発音中のボイス数と、プラグインが使っているプロセッサーの割合が表示されます。

ボタン :guilabel:`パニック` は、すべての音を止めてコントローラーをリセットします。ノートが鳴りっぱなしになったときに便利です。


## 設定 {#doc_settings}


ボタン :guilabel:`設定` で、次のオプションを含むメニューが開きます。

:guilabel:`同時発音数`
: ボイスの最大数です。64～4096の範囲で指定します（初期設定は1024）。
  この数を超えると、最も小さい音のノートからフェードアウトします。

:guilabel:`キーボード`
: ウィンドウのキーボードで演奏するノートのMIDIチャンネルです。

:guilabel:`言語`
: プラグインの言語です。初期設定ではシステムの言語になります。
  この選択は、プラグインのすべてのインスタンスで共有されます。
  ホストに渡されるパラメーター名と出力名は、プラグインを読み込んだときの言語になります（LV2では常に英語です）。

:guilabel:`固定レイテンシー（ノートを正確な位置で発音）`
: このオプションが無効（既定）の場合、オーディオブロック内のMIDIメッセージはまとめて前に移動され、ブロックの最初のノートがブロックの先頭で鳴り始めます。ライブで演奏したノートは平均してバッファの半分の長さだけ早く鳴りますが、レイテンシーはホストのバッファ内での位置によって変わります。
  有効にすると、各メッセージは正確な位置で処理され、ライブで演奏したノートのレイテンシーは一定になります。
  オフラインのエクスポート中は、メッセージは常に正確な位置で処理されます。

:guilabel:`[-1; 1] へのクリッピング`
: 出力は[-1; 1]の範囲に制限されます（既定）。Polyphoneと同じ動作です。
  クリッピングしない場合、より大きな値はそのままホストに渡され、ホストが浮動小数点数としてミックスします。ゲインを上げても飽和せず、レベルはホストの出力の前で調整します。

:guilabel:`SoundFont をプロジェクトに保存`
: SoundFontをホストのプロジェクトに保存します。これにより、ファイルがなくても別のコンピューターでプロジェクトを開けます。
  sfzファイルはサンプルが別のファイルになっているため、この機能は使えません。

:guilabel:`チャンネルとエフェクトを個別の出力へ`
: メイン出力に加えて、出力「チャンネル 1」～「チャンネル 16」にはそれぞれのチャンネルのノートがエフェクトなしで送られ、出力「エフェクト」にはリバーブとコーラスに送られる成分が送られます。
  ホストで出力が有効になっていないチャンネルは、メイン出力に残ります。
  このオプションが無効の場合（初期設定）は、すべてがメイン出力にミックスされます。


## プロジェクトでの使用 {#doc_project}


ホストのプロジェクトには、パラメーター、演奏する楽器、同時発音数、SoundFontのパス（プロジェクトに保存する場合はSoundFontの内容）が保存されます。
プロジェクトを開くと、ほかの設定を復元する前にSoundFontの構造だけが読み込まれます。ホストはサンプルの読み込みを待たず、オフラインのエクスポートもすぐに開始できます（まだ読み込まれていないサンプルは待ちます）。

オフラインのエクスポート中、およびリアルタイムで[固定レイテンシー](manual/plugin.md#doc_settings)を使用する場合、ノートはホストのバッファサイズにかかわらず、MIDIメッセージの位置ちょうどで鳴り始めます。
オフラインのエクスポート中は、プロセッサーの負荷によってボイス数が制限されることはありません。
