Polyphoneは、デジタルオーディオワークステーション（DAW）やその他のオーディオプラグインのホストで使えるプラグインとしても提供されています。
このプラグインは、sf2、sf3、sfz、dls形式のSoundFontをPolyphoneのシンセサイザーで演奏します。そのため、SoundFontはホストでもエディターでも同じ音で鳴ります。
プラグインはSoundFontを演奏しますが、編集はしません。変更はPolyphoneで行い、その後SoundFontをプラグインで開き直します。

プラグインは、Linux、Windows、macOSでVST3、CLAP、LV2の形式で利用でき、macOSではAudio Unit（AU）の形式でも利用できます。


![Polyphoneプラグイン](images/plugin.png "Polyphoneプラグイン")


## インストール {#doc_install}


プラグインはOSごとのアーカイブで配布されており、「[ソフトウェア](software)」セクションから入手できます。
ホストで使う形式を、ホストがプラグインを探すフォルダーにコピーしてから、ホストでプラグインを再スキャンします。

Linux
: :file:`Polyphone.vst3` を :file:`~/.vst3/` に\
  :file:`Polyphone.clap` を :file:`~/.clap/` に\
  :file:`Polyphone.lv2` を :file:`~/.lv2/` に

macOS
: :file:`Polyphone.vst3` を :file:`~/Library/Audio/Plug-Ins/VST3/` に\
  :file:`Polyphone.clap` を :file:`~/Library/Audio/Plug-Ins/CLAP/` に\
  :file:`Polyphone.component` を :file:`~/Library/Audio/Plug-Ins/Components/` に（Audio Unit形式。Logic ProとGarageBandで使われます）\
  :file:`Polyphone.lv2` を :file:`~/Library/Audio/Plug-Ins/LV2/` に

Windows
: :file:`Polyphone.vst3` を :file:`C:\Program Files\Common Files\VST3` に\
  :file:`Polyphone.clap` を :file:`C:\Program Files\Common Files\CLAP` に\
  :file:`Polyphone.lv2` を :file:`%APPDATA%\LV2` に

macOSでは、プラグインは公証（notarization）を受けていません。ホストがプラグインを読み込まない場合は、ダウンロードしたファイルの隔離フラグを削除してください。たとえば次のようにします。

```
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Polyphone.vst3
```


## SoundFont {#doc_soundfont}


ウィンドウの上部には、SoundFontの名前とパスが表示されます。
SoundFontは次の方法で開きます。

* ボタン :guilabel:`開く...` を使う
* その右の矢印を使う（最近開いた10個のSoundFontが一覧表示されます）
* ファイルをウィンドウにドロップする

sfzファイルとdlsファイルは、Polyphoneがインポートするときと同じように変換されます。sfzファイルのサンプルは、そのファイルが参照するオーディオファイルです。
SoundFontは開いたときに全体が読み込まれ、sf3ファイルのサンプルは展開されます。演奏中にディスクから読み込むことはありません。
プラグインの複数のインスタンスが同じファイルを演奏する場合（たとえばトラックごとに1つ）、ファイルの読み込みとメモリへの保持は1回だけです。
ファイルが変更された場合（たとえばPolyphoneで保存し直した後）は、再び読み込まれます。


## 演奏モード {#doc_modes}


プリセットのリストの上にある3つのボタンで、プリセットの演奏方法を選びます。

:guilabel:`単一プリセット`
: リストで選択したプリセットを、16のMIDIチャンネルすべてで演奏します。
  プリセットは、バンク番号とプリセット番号付きで表示されます（たとえば「000:024 Guitar」）。

:guilabel:`16 チャンネル`
: 各MIDIチャンネルが、その行で選んだそれぞれのプリセットを演奏します。
  :guilabel:`プログラムチェンジ` を選ぶと、General MIDIシンセサイザーと同じように、チャンネルが受信したバンクセレクトとプログラムチェンジのメッセージで選ばれたプリセットを演奏します。このとき、チャンネル10ではドラム用にバンク128が使われます。
  演奏中のプリセットは各行の右に表示されます。
  このモードは、複数の楽器用にアレンジされたMIDIファイルを演奏するのに便利です。

:guilabel:`MPE`
: 選択したプリセットをMPE（MIDI Polyphonic Expression）コントローラーで演奏します。各ノートが独自のチャンネルを持つため、ピッチベンド、プレッシャー、音色（CC 74）もノートごとに独立しています。
  コントローラーが設定（RPN 6）を送ってくるまでは、15チャンネルの下位ゾーンが使われます。
  ゾーンのマスターチャンネルは、そのゾーンのすべてのノートに作用します。マスターチャンネルのピッチベンドは各ノートのピッチベンドに加算され、そのコントローラーはすべてのノートに適用されます。
  ピッチベンドの範囲は、ノートでは48半音、マスターチャンネルでは2半音で、コントローラーから変更できます（RPN 0）。


![「16 チャンネル」モードのプラグイン](images/plugin_channels.png "「16 チャンネル」モードのプラグイン")


## パラメーター {#doc_parameters}


右側のパラメーターはPolyphoneのシンセサイザーのもので、Polyphoneの[サウンド](manual/settings.md#doc_sound)と[キーボード](manual/settings.md#doc_keyboard)の設定にも同じものがあります。

:guilabel:`シンセ`
: :guilabel:`ゲイン`（-50～+50 dB）、:guilabel:`トランスポーズ`（-24～+24半音。ドラムはトランスポーズされません）、:guilabel:`チューニング`（A4の基準ピッチ、400～480 Hz）、:guilabel:`音律`（微調整は、リストの下で選んだキーに対する値です）。

:guilabel:`リバーブ`
: :guilabel:`レベル`、:guilabel:`サイズ`、:guilabel:`幅`、:guilabel:`ダンプ`。

:guilabel:`コーラス`
: :guilabel:`レベル`、:guilabel:`デプス`、:guilabel:`周波数`。

これらのパラメーターはすべて、ホストでオートメーションできます。


## キーボードとステータス {#doc_keyboard}


ウィンドウ下部のキーボードには受信したノートが表示され、マウスで演奏することもできます。
その下には、発音中のボイス数と、プラグインが使っているプロセッサーの割合が表示されます。

ボタン :guilabel:`パニック` は、すべての音を止めてコントローラーをリセットします。ノートが鳴りっぱなしになったときに便利です。


## 設定 {#doc_settings}


ボタン :guilabel:`設定` で、次のオプションを含むメニューが開きます。

:guilabel:`同時発音数`
: ボイスの最大数です。64～4096の範囲で指定します（初期設定は1024）。
  この数を超えると、最も小さい音のノートからフェードアウトします。

:guilabel:`キーボード`
: ウィンドウのキーボードで演奏するノートのMIDIチャンネルです。

:guilabel:`言語`
: プラグインの言語です。初期設定ではシステムの言語になります。
  この選択は、プラグインのすべてのインスタンスで共有されます。
  ホストに渡されるパラメーター名と出力名は、プラグインを読み込んだときの言語になります（LV2では常に英語です）。

:guilabel:`SoundFont をプロジェクトに保存`
: SoundFontをホストのプロジェクトに保存します。これにより、ファイルがなくても別のコンピューターでプロジェクトを開けます。
  sfzファイルはサンプルが別のファイルになっているため、この機能は使えません。

:guilabel:`チャンネルとエフェクトを個別の出力へ`
: メイン出力に加えて、出力「チャンネル 1」～「チャンネル 16」にはそれぞれのチャンネルのノートがエフェクトなしで送られ、出力「エフェクト」にはリバーブとコーラスに送られる成分が送られます。
  ホストで出力が有効になっていないチャンネルは、メイン出力に残ります。
  このオプションが無効の場合（初期設定）は、すべてがメイン出力にミックスされます。


## プロジェクトでの使用 {#doc_project}


ホストのプロジェクトには、パラメーター、演奏するプリセット、同時発音数、SoundFontのパス（プロジェクトに保存する場合はSoundFontの内容）が保存されます。
プロジェクトを開くと、ほかの設定を復元する前にSoundFontが読み込まれるため、オフラインのエクスポートをすぐに開始できます。

ノートは、ホストのバッファサイズにかかわらず、MIDIメッセージの位置ちょうどで鳴り始めます。
オフラインのエクスポート中は、プロセッサーの負荷によってボイス数が制限されることはありません。
