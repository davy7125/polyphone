ソフトウェアの設定は、[ホーム画面](manual/index.md)または[メニュー](manual/menu.md#doc_shortcuts)から開けます（ショートカット :kbd:`Ctrl`+:kbd:`,`）。
設定は次の5つのセクションに分かれています。

* [一般](#doc_general)
* [インタフェース](#doc_interface)
* [サウンド](#doc_sound)
* [キーボード](#doc_keyboard)
* [オンラインリポジトリ](#doc_repository)

変更はすべて即座に保存されます。


## 一般 {#doc_general}


:guilabel:`一般` セクションでは、次のパラメーターを変更できます。

オーディオバックエンド
: 音の再生に使うオーディオシステムとデバイスを指定します。
  使用できるシステムはOSによって異なります（たとえば、WindowsではWASAPIとASIO、LinuxではALSAとJACK、macOSではCore Audio）。
  「-」を選ぶと、オーディオ出力がオフになります。

バッファサイズ
: オーディオバッファのサイズを指定します。
  バッファを小さくするとレイテンシーは小さくなりますが、音にノイズが混じることがあります。
  値を :guilabel:`デフォルト` にすると、サイズはオーディオシステムに応じて決まります。

同時発音数
: 同時に再生されるボイスの最大数です。64～4096の範囲で指定します（初期設定は1024）。
  ボイスとは再生中のサンプルのことで、1つのノートが複数のボイスを使うことがあります（たとえばステレオサンプルでは2つ）。
  この数を超えると、まず離されたノート、次に最も小さい音から順にフェードアウトします。
  鳴り始めたばかりのノートと、押さえているキーのうち最も高いキーと最も低いキーは、できるだけ長く保持されます。

プロセッサー負荷
: ボイスの計算に使用するプロセッサー時間の最大割合です。20～100%の範囲で指定します（初期設定は60%）。
  この割合を超えると、同じようにノートがフェードアウトします。
  値を大きくすると同時に鳴らせるノートが増えますが、音にノイズが混じることがあります。

MIDI入力
: シンセサイザーと仮想キーボードを操作するMIDI入力を指定します。

さらに、次のオプションにチェックを入れることができます。

ステレオ編集：リンクされたサンプルを変更
: ステレオサンプルの片側を編集すると、もう片側にも自動的に同じ編集が行われます。
  ステレオのインストゥルメントのディビジョンを編集する場合も同様で、もう一方のチャンネルに対応するディビジョン（キー範囲とベロシティ範囲が同じもの）にも同じ編集が行われます。

サンプルインポート：ループの終点までトリム
: サンプルをインポートするときに、ループの終了位置より後ろにあるデータが自動的に削除されます（「[ループの終点までトリム](manual/soundfont-editor/tools/sample-tools.md#doc_trimloop)」ツールと同じ効果です）。

サンプルインポート：先頭の空白を削除
: サンプルをインポートするときに、アタックの開始より前にある空白部分が自動的に削除されます（「[先頭の空白を削除](manual/soundfont-editor/tools/sample-tools.md#doc_removeblank)」ツールと同じ効果です）。

## インタフェース {#doc_interface}


このセクションには、ソフトウェアのインタフェースに関するオプションがあります。

言語
: ここで言語を変更できます。

キー名
: キーの名前は、（MIDI仕様に従った）キー番号で表示するか、中央のCの名前（C3、C4、C5）に基づいて表示できます。
  キー名にはシャープまたはフラットを使えます。

単一インスタンス
: すべてのファイルを1つのウィンドウで開きます。

起動時の表示
: SoundFontを開いたときに表示する画面を、:guilabel:`一般情報`（初期設定）、:guilabel:`サンプルリスト`、:guilabel:`最初のサンプル`、:guilabel:`インストゥルメントリスト`、:guilabel:`最初のインストゥルメント`、:guilabel:`プリセットリスト`、:guilabel:`最初のプリセット` の中から選びます。

ディビジョンを並べ替え
: インストゥルメントやプリセット内のディビジョンの並び順を、:guilabel:`キー範囲で`、:guilabel:`ベロシティ範囲で`、:guilabel:`アルファベット順で`、:guilabel:`なし`（作成順）のいずれかに変更できます。

スタイル
: インタフェース要素のスタイルです。
  初期設定のスタイルは :guilabel:`Fusion` で、OSによってはその他のスタイル（Adwaita、Windows、macOSなど）も選べます。

色
: 定義済みのさまざまな配色を使って、Polyphoneの外観をカスタマイズできます。
  テキスト、ウィンドウ、ボタン、選択範囲、リストの色を手動で選ぶこともできます。
  色を変更できるのは、スタイルが :guilabel:`Fusion` または :guilabel:`Windows` の場合だけです。

ウィンドウボーダー
: ウィンドウの枠を表示または非表示にし、画面のスペースを節約します（macOSでは使用できません）。

装飾
: 一部のリストにある背景の装飾は、見やすさのために無効にできます。

言語、キー名、スタイル、色、ウィンドウボーダー、装飾の変更は、次回ソフトウェアを起動したときに適用されます。


![設定：インタフェース](images/settings_interface.png "設定：インタフェース")


## サウンド {#doc_sound}


:guilabel:`サウンド` セクションでは、シンセサイザーのリバーブ（レベル、ルームサイズ、ダンピング、幅）とコーラス（レベル、深さ、周波数）、および全体の音量を変更できます。
外部キーボードを接続している場合は、MIDIのボリュームコントローラーで全体の音量を変更できます。

フィルターのカットオフ周波数を変更するデフォルトモジュレーターは、sf2仕様のバージョン2.01と2.04の間で変更されたため、どちらのバージョンを使うかをここで指定できます。

* :guilabel:`SoundFont 2.01`：「ベロシティが64未満の場合に限り、ベロシティに応じてフィルター周波数を下げる」という規則を使います（ベロシティ63と64の間で、はっきりとした問題のある段差が聞こえます）。
* :guilabel:`SoundFont 2.04`（初期設定）：「ベロシティに応じてフィルター周波数を下げる」という規則を使います（段差はなくなります）。
* :guilabel:`無効`：このデフォルトモジュレーターは設定されません。


![設定：サウンド](images/settings_sound.png "設定：サウンド")


## キーボード {#doc_keyboard}


[仮想キーボード](manual/soundfont-editor/toolbar.md#doc_keyboard)の操作に使うコンピューターのキーボードのキーは、:guilabel:`キーボード` セクションで定義します。
:guilabel:`最初のC` の設定で、音の高さをオクターブ単位で上げ下げできます。

上級者向けに、ここでチューニングを変更することもできます。

基準ピッチ
: 中央のCの上にあるA（キー69）の周波数です。390～470 Hzの範囲で指定します（初期設定は440 Hz）。

音律
: 演奏時に、平均律以外の音律を適用できます。
  音律を選択した場合は、その音律の基準となるキー（主音）も選べます。

基準ピッチと音律は、MIDIのRPNメッセージ（マスターファインチューニング、チューニングプログラムセレクト、チューニングバンクセレクト）でも変更できます。


![設定：キーボード](images/settings_keyboard.png "設定：キーボード")


## オンラインリポジトリ {#doc_repository}


ここにアカウントのメールアドレスとパスワードを入力すると、Polyphoneをそのアカウントに関連付けられます。[プレミアムアカウント](premium)では、[オンラインリポジトリ](manual/online-repository.md)全体を利用できます。
接続に成功すると、:guilabel:`ログアウト` ボタンを押すまで、Polyphoneは起動するたびに自動的にアカウントに接続します。

[オンラインリポジトリ](manual/online-repository.md)からSoundFontをダウンロードするときに使うディレクトリも、ここで変更できます。


![設定：リポジトリ](images/settings_repository.png "設定：リポジトリ")
