## 表格 {#doc_table}


### 简介


表格可以总览并编辑乐器的配置。
在 :guilabel:`全局` 分区中修改某个参数，会应用到所有分区，但已经单独指定了该参数的分区除外（局部覆盖）。

以斜体显示的行（:guilabel:`采样根音`、:guilabel:`采样长度` 和 :guilabel:`循环`）不可编辑：它们只是提示每个分区所链接采样的属性，仅供参考。

可编辑的参数有：

音符范围
: 能听到该采样的音符范围。

力度范围
: 能听到该采样的力度范围。
  可以为同一个音符设置不同力度范围的不同声音，例如用来区分钢琴琴键的不同力度层次。

衰减(分贝)
: 应用于采样的衰减量，以分贝为单位。\
  注意：sf2 格式不允许在乐器层级将该值设为负数，因此无法进行放大。

声像
: 应用于声音的声像平衡，使其在立体声中偏左或偏右。

循环播放
: ![循环关闭](images/loop_off.png "循环关闭"){.inline} 表示声音不循环播放。
  ![循环开启](images/loop_on.png "循环开启"){.inline} 表示声音持续循环。
  ![释音](images/sample_mode_release.png "释音"){.inline} 用于在松开琴键时触发采样播放。音量仍由音量包络决定，并会加入一个很短的起音（0.2 毫秒），以便在释音时平滑地开始播放采样。
  ![循环开启 + 释音](images/loop_on_end.png "循环开启和释音"){.inline} 表示在按住琴键期间循环播放，松开后继续播放采样的剩余部分。\
  注意：“释音”播放模式并未在 sf2 格式中定义，因此 FluidSynth 等其他播放器可能不会实现它。
  实现这种效果的另一种方法是，为每个采样再配一个采样，其中包含一个很短的静音循环，后接松开琴键时要发出的声音。
  新增的采样以“循环开启 + 释音”播放参数读取。
  请参阅教程“[在乐器中使用自定义释音](tutorials/using-custom-releases-in-an-instrument.md)”。

根音符
: 可以将采样原本的根音符改为另一个音符。
  例如，如果某个采样的根音符为 50，并在音符范围 [49 — 51] 内演奏，那么它在音符 49、50 和 51 上的初始移调分别为 -1、0 和 +1 个半音。
  如果随后在乐器层级将根音符覆盖为 51，则同一个采样在音符 49、50 和 51 上的初始移调分别为 -2、-1 和 0 个半音。

调音（半音和音分）
: 以半音和百分之一半音为单位调整音高。
  这个移调会叠加在由所触发音符产生的初始移调之上（例如，根音符为 60 的采样，如果按下的琴键是 62，则初始移调为 +2 个半音）。

调音（音阶）
: 该参数修改两个相邻音符之间的音程，因此会影响由所触发音符产生的初始移调。
  值为 100 表示平均律音阶：从一个音符到下一个音符，采样移调 100 音分。
  值为 0 则禁用这种初始移调，即采样在键盘上所有琴键上的播放效果完全相同。

滤波器
: 应用一个低通滤波器，可指定截止频率和共振。

音量包络
: 修改音量包络，以及它随音符变化的方式（可选）。

调制
: 设置一个调制（包络、延迟、频率、随音符的变化）及其对音调、滤波器和音量的影响。

颤音
: 设置一个颤音（延迟、频率）及其对音调的影响。

独占类
: 通过为一个类中的一组分区设置相同的非 0 参数值，该参数可以定义一个或多个独占类。
  定义独占类后，从该独占类的任一分区触发的音符都会终止同一类中的所有其他声音。
  独占类的作用范围是定义该类的预设（如果两个乐器在同一个预设中，一个乐器中触发的声音会终止另一个乐器的声音）。
  这种效果可用于镲片之类的打击乐器。
  简单来说，演奏一个音符会自动终止同一组中的另一个音符。

合唱和混响
: 表示合唱和混响效果的强度。
  这些效果可以在软件[设置](manual/settings.md#doc_sound)中配置。

固定音符和力度
: 在分区的整个范围内强制使用固定的音符值和力度值。

偏移
: 修改播放时声音的起点和终点位置，以及循环的起点和终点位置。
  偏移的单位是采样点（采样值的数量）。


### 表格中的编辑辅助功能


为了让表格编辑更方便快捷，提供了以下功能：

* 可以用鼠标滚轮修改数值（单元格需要先处于编辑模式），
* 可以用外部 MIDI 键盘（或[虚拟键盘](manual/soundfont-editor/toolbar.md#doc_keyboard)）设置根音符、音符范围和力度范围（单元格需要先处于编辑模式），
* 多选单元格后编辑最后一个单元格，会同时编辑所有单元格，
* :kbd:`Del` 和 :kbd:`Backspace` 键会清除所有选中单元格的内容，
* 如果在软件[设置](manual/settings.md#doc_general)中启用了相应选项，可以同时编辑立体声分区，
* 根据[设置](manual/settings.md#doc_interface)中选择的选项，音符名称可以显示为数字或文字（以 C3、C4 或 C5 作为中央 C），
* 可以用 :kbd:`Ctrl`+:kbd:`C` / :kbd:`Ctrl`+:kbd:`V` / :kbd:`Ctrl`+:kbd:`X` 复制 / 粘贴 / 剪切一组单元格（不必相邻）。

别忘了可用的[工具](manual/soundfont-editor/tools/instrument-tools.md)！
尤其是可以进行[基于音符的配置](manual/soundfont-editor/tools/instrument-tools.md#doc_global)的工具。

在分区标题上单击右键即可使用这些选项，在[树状图](manual/soundfont-editor/tree.md#doc_menu)的右键菜单中也可以找到。

## 范围编辑器 {#doc_range}


范围编辑器可以按照音符范围和力度范围，快速且直观地安排采样。
这个图形还能突出显示配置中的问题，例如没有采样的区域或不需要的重叠。


![范围编辑器](images/edit_range.png "范围编辑器")


每个采样都用一个半透明矩形表示，因此可以看出多个元素的重叠情况。


### 选择矩形


在某个矩形上单击左键会选中它，并取消其他所有选择。
如果多个矩形重叠，连续单击会依次切换鼠标指针下方的选择。
双击某个矩形会打开对应的[采样](manual/soundfont-editor/editing-pages/sample-editor.md)（在[预设编辑器](manual/soundfont-editor/editing-pages/preset-editor.md)中则打开对应的乐器）。

可以进行多选：

* 按住 :kbd:`Ctrl` 键，然后逐个单击要选择的矩形，
* 使用 :kbd:`Shift` 键：会选中第一个被单击的矩形与下一个被单击的矩形之间的所有矩形。


### 修改矩形


选中一个或多个矩形后，可以用鼠标左键：

* 拖动矩形的某条边来改变大小；
* 指向矩形中心并拖动来改变位置。

如果选中了多个矩形，所有修改会同步进行。
按 :kbd:`Esc` 键可以取消正在进行的修改。


### 平移和缩放


按住右键可以围绕所选点进行缩放。

如果起始点不在矩形上，按住左键可以平移图形。

单击鼠标中键会演奏一个音符：音符由鼠标的水平位置决定，力度由其垂直位置决定。


## 包络编辑器 {#doc_envelope}


包络编辑器以图形方式展示定义音量包络的 8 个参数和定义调制包络的 8 个参数。
因此，它是更好地理解每个参数作用的工具。


![包络编辑器](images/edit_envelope.png "包络编辑器")


图形上方的按钮用于在音量包络（绿色显示）和调制包络（红色显示）之间切换编辑对象。
编辑调制包络时，音量包络以细线显示。

图形左侧部分表示**按下**琴键时包络的变化。
8 个参数中有 7 个参与了这一部分的表示：

延迟(Delay)
: 按下琴键后，包络保持为 0 的时长。在大多数情况下，我们希望按下琴键后立即听到声音，因此该参数保持为零。不过，**延迟**很有用，例如在制作由多层声音构成、更加丰富的铺底音色时。假设我们想在按下琴键 0.5 秒后引入第二层声音，只需在该字段中输入“0.5”。延迟不会推迟声音的播放，而是将其静音。如果将延迟设为 0.5 秒，我们会从采样播放 0.5 秒后的位置开始听到它，前 0.5 秒是在静音状态下播放的。

起音(Attack)
: 在**延迟**之后，包络从 0 增长到最大值的时长。例如，小提琴这类弓弦乐器的起音相当长，而吉他这类拨弦乐器的起音则非常短。即使想要尽可能短的起音，也建议至少输入 0.001，否则按下琴键后可能会听到“咔嗒”声。

保持(Hold)
: 在**起音**之后，包络保持最大值的时长。

衰减(Decay)
: 在**保持**之后，包络从最大值逐渐降到**延音**所指定值的时长。如果**延音**中没有指定任何衰减量（0 dB，默认值），那么无论该值设为多少，**衰减**期间的音量都会保持在最大值。

延音(Sustain)
: 在**衰减**之后、松开琴键之前一直保持的值。与**衰减量**一样，延音值是以分贝表示的衰减。如果想在衰减时间之后将音量降低一半，需要设为 6 dB。如果想完全静音，可以设为“144”。

音符 → 保持
: 根据音符改变**保持**的时长（见下文）。

音符 → 衰减
: 根据音符改变**衰减**的时长（见下文）。

**音符 → XXX** 为正值时，XXX 的时长会向高音方向逐渐缩短；为负值时则相反。
例如：

* 值为 100 时，中央 C（60）以上每升高一个八度，XXX 的时长减半；中央 C 以下每降低一个八度，XXX 的时长加倍，
* 值为 -100 时，中央 C（60）以上每升高一个八度，XXX 的时长加倍；中央 C 以下每降低一个八度，XXX 的时长减半。

在制作踩下延音踏板的吉他或钢琴时，这些参数会很有用：音越低，持续时间越长，直到完全听不到声音为止。

右侧部分表示**松开**琴键时包络的变化。
只有**释音**时长参与这一部分的表示。
在这段时间内，包络会逐渐回到 0。
小提琴或合成器铺底音色的释音时间相对较长，而管风琴等其他声音的释音时间则非常短。实际上，即使是很短的释音时间，也建议至少设为 0.2 秒，因为过短的释音听起来既不悦耳也不自然（不过这也取决于你对所要制作的乐器的设想）。

如果在树状图中只选中了乐器的一个分区，对应的[采样](manual/soundfont-editor/editing-pages/sample-editor.md)会显示在背景中。
这样可以更直观地看到包络相对于所播放采样的变化。


### 移动点


可以用鼠标左键移动曲线上的每个点：

* **延迟**、**起音**、**保持**和**释音**的终点沿水平方向移动；
* **衰减**的终点可以沿两个方向移动：水平方向调整**衰减**，垂直方向调整**延音**；
* 松开按键的点沿垂直方向移动，用于调整**延音**。

鼠标指针下方的点的参数及其值会显示在图形上方的一角。
如果多个点位于同一位置，圆会被分成几部分，从左到右依次对应从第一个阶段到最后一个阶段。

**音符 → 保持**和**音符 → 衰减**通过一把穿过**保持**或**衰减**终点的小标尺来编辑：标尺的上端表示该分区最高音符的时长，下端表示最低音符的时长。
移动一端只会改变对应音符的时长，另一端保持不动；按住 :kbd:`Ctrl` 键时，两端会围绕标尺中点移动。
当鼠标靠近该点时会显示标尺；当参数不为 0 时，标尺会一直显示。

按住 :kbd:`Shift` 键可以进行更精细的调整。
将点推到图形右边缘时，视图会滚动或缩小，以便设置更长的时长。
按 :kbd:`Esc` 键可以取消正在进行的修改。
双击某个点会重置其参数（对于标尺的一端，仅重置**音符 → 保持**或**音符 → 衰减**），重新使用 :guilabel:`全局` 分区的值或默认值。

如果选中了多个分区或乐器，它们的所有包络会一起修改：时长按相同比例变化，其他值按相同幅度变化。


### 平移和缩放


按住右键可以围绕所选点进行缩放。

如果单击不是从曲线上的点开始，按住左键可以平移图形。


## 音色视图 {#doc_timbre}


音色视图沿整个键盘显示乐器**实际听到的**音色：即每个谐波的电平，此时每个采样都已移调到它所演奏的音符，并已应用其分区的衰减、滤波器和调制器。
这样可以看出不规则之处，尤其是采样之间衔接处的断层。
在此视图中，可以创建计算音符、移除冗余的采样，以及校正某个采样的音色或电平。
该视图只负责测量并给出建议，不会自动应用任何修改。


![音色视图](images/edit_timbre.png "音色视图")


### 纳入计算的分区


视图显示的是以左上角所选力度演奏时听到的内容（默认为 100，之后为上次使用的力度）。
旁边的条显示乐器的力度层：单击某一层会选中该层中间的力度。

纳入计算的分区是在该力度下发声、未被[静音](#doc_solo)、并且不是只在松开琴键时才播放（“释音”播放模式）的分区。
因此，要将某个分区（例如噪声或释音声音）排除在视图之外，只需将其静音。
启用[选定独奏](manual/soundfont-editor/tree.md#doc_menu)时，静音状态会随选择而变化，因此不予考虑。
演奏同一音符的多个分区（立体声对、叠加的层）会被合并：它们的功率相加。

一个**根音符**汇集了具有该根音符的所有分区，可能包含多个音符范围。
采样会在后台进行分析（右上角显示剩余的采样数量）：谐波在循环上测量，如果没有循环，则在声音的稳定部分上测量。
这些分析结果会一直保留，直到采样的数据、循环、根音符或音高校正发生变化。


### 图谱


每一列对应一个音符，与下方显示的键盘对齐；每一行对应一个谐波次数（H1：基音，H2：第二谐波……），与频谱图一样，第 1 次谐波位于底部。
前几次谐波逐个显示，之后的谐波按频段分组（参见[分音](#doc_timbre_partials)）。

图谱上方的摘要行为每个音符显示：

* :guilabel:`电平`：总电平，
* :guilabel:`音色`：根音符相对于其参考的音色偏差（在参考可靠性较低的键盘两端以斜线阴影显示），
* :guilabel:`移调`：采样向下移调时为蓝色，向上移调时为红色，
* 以及在 :guilabel:`选项` > :guilabel:`摘要` 菜单中选择的行：:guilabel:`亮度`（各次谐波的重心）、:guilabel:`奇次 / 偶次`（奇次谐波与偶次谐波的比较）、:guilabel:`噪声`（谐波与噪声之比）、:guilabel:`音准`（与平均律最接近的音符相差的音分数）和 :guilabel:`循环`（循环的质量）。

在图谱上，竖线标出分区之间的衔接处（采样改变时线更粗），圆点标出每个根音符，斜线阴影表示不存在的谐波（超出采样或输出的频带、高于上限）或无法可靠测量的谐波，不发声的音符显示为灰色。
提示信息会显示鼠标指针下方单元格的数值：音符、谐波次数、电平、偏差、采样、移调和时长系数（采样向上移调时，起音、震音和拍频会变快）。

:guilabel:`显示` 列表用于选择颜色所表示的内容：

绝对电平
: 各次谐波的电平，以 dB 为单位。

相对电平
: 各次谐波相对于该音符最强谐波的电平：即不受电平影响的音色。

与参考的偏差
: 在根音符所演奏的所有音符上，根音符与其参考在各次谐波上的差值：过强（红色）或过弱（蓝色）。

跳变
: 与前一个音符的差值：即衔接处的断层。

移调
: 音符与其采样的根音符之间相差的半音数。

置信度
: 功率中能够可靠测量的部分所占的比例。

:guilabel:`选项` 菜单还可以选择显示整个键盘或每个根音符只显示一列、按阈值分级着色（容差范围内的偏差显示为中性色），以及播放所单击的音符。
图谱下方的键盘以视图的力度演奏该乐器。


### 参考与判定


根音符的**参考**是其相邻根音符所预测的结果：在该根音符的音符上演奏相邻的根音符（使用它们各自分区的参数），然后以 dB 为单位逐次谐波地对它们的电平进行插值。
在键盘两端，参考由同一侧的两个相邻根音符外推得出，可靠性较低。
选择 :guilabel:`局部回归` 时，改为使用基于每侧多个相邻根音符的稳健回归，使有缺陷的相邻根音符影响更小。

根音符与其参考之间的偏差用两个数值概括：

* **电平**偏差：总电平之差，可以通过衰减来校正，
* **音色**偏差：去除电平偏差后各行差值的平均值，每一行按其响度加权（较弱的谐波也会被计入，但不会占主导）。

:guilabel:`判定` 条为每个根音符和每个衔接处给出一个标签，以形状和颜色表示：

一致 ✓（绿色）
: 音色偏差在容差范围内。

冗余 −（蓝色）
: 该根音符是一致的，并且移除它之后，其音符的变化小于 :guilabel:`冗余` 阈值，新的衔接处也不会出现断层：可以将其移除。

待校正 ~（橙色）
: 音色偏差介于容差和最大值之间：可以校正音色。

差异过大 ×（红色）
: 音色偏差超过最大值：可以移除该根音符，或将其替换为计算音符。

断层 +（紫色）
: 在采样变化处，音色跳变超过 :guilabel:`断层` 阈值，并且两个根音符之间存在没有采样的音符：可以在那里创建计算音符。

电平 ▲ ▼（黄色）
: 电平偏差超过 :guilabel:`电平` 阈值（▲ 过响，▼ 过轻）：可以校正衰减。

阈值在 :guilabel:`阈值` 菜单中设置。
它们的默认值（:guilabel:`容差` 4.5 dB、:guilabel:`最大值` 8 dB、:guilabel:`冗余` 2.5 dB、:guilabel:`断层` 6 dB、:guilabel:`电平` 2.5 dB）来自管风琴采样集，在这些采样集中，70% 的根音符与其相邻根音符的偏差小于 4.5 dB：可以根据乐器调整这些值。
衔接处或偏差也可能是有意为之（一个乐器逐渐变成另一个乐器、混合音栓的音高回落）：这些标签仅仅是建议。


### 分音 {#doc_timbre_partials}


:guilabel:`分音` 菜单用于设置图谱的行，这些行同时用于显示、偏差计算和校正：

逐个显示的谐波数
: 逐个显示和比较的谐波次数的数量（默认为 10）。人耳能够分别听出前几个谐波，而之后的谐波则被整体感知为亮度。

后续谐波
: 之后的谐波按三分之一八度（11-12、13-16、17-20……）或一个八度分组为频段，使大量较弱的高次谐波的权重不会超过前几次谐波。

上限
: 高于此频率的分音会被忽略（默认为 16 kHz，或采样率的一半）。

动态范围
: 比该音符最强谐波低出此值以上的谐波不参与比较（默认为 60 dB）。


### 详情与操作


单击某个音符，会在图谱下方显示它所演奏的内容：各个采样及其移调、衰减和滤波器、时长系数、音高、根音符的偏差，以及移除该根音符会带来的变化。
条形图将听到的电平与参考进行比较；对于没有采样的音符，则与可以为其创建的计算音符（图谱上的虚线列）进行比较。

单击某个根音符会在[树状图](manual/soundfont-editor/tree.md)中选中其分区，反之，在树状图中选中分区也会选中其根音符。
可以按住 :kbd:`Ctrl` 或 :kbd:`Shift` 键，或在音符上拖动鼠标，来选择多个根音符。

右侧的按钮和图谱的右键菜单作用于所选的根音符：

在此创建音符...
: 用于没有采样的音符：将最近的根音符移调，并根据第二个根音符对其谐波电平进行插值（或外推）。可以选择所用的根音符，当该音符距离它们较远时会显示警告。周围的音符范围会相应调整；完全位于新音符范围内的分区会被移除。

移除...
: 移除该根音符的分区，由其相邻根音符接管它的音符。也可以同时移除不再使用的采样。

替换为计算音符...
: 移除该根音符，然后根据其相邻根音符重新创建。

校正音色...
: 打开[校正](#doc_timbre_correction)窗口。

校正电平
: 修改分区的衰减，使电平偏差变为零（衰减不能为负数）。

通过渲染检查
: 由音频引擎演奏该音符，并测量结果的谐波：测量结果会显示在条形图上，用于检验视图的计算。

将这些分区静音
: 位于右键菜单中：将这些分区排除在视图之外。

:guilabel:`建议` 菜单会选中所有带有标签的根音符（或衔接处），并在确认后对其执行相应的操作：校正待校正的根音符、替换差异过大的根音符、移除冗余的根音符、在断层处创建计算音符、校正偏离的电平。
处理顺序从最差到最轻微，每次操作后都会重新计算参考：有缺陷的根音符也会扭曲其相邻根音符的参考，使它们在该根音符被校正之前看起来也有一半像是有缺陷的。

每个操作或每一系列操作都可以一步撤销（:kbd:`Ctrl`+:kbd:`Z`）。


### 音色校正 {#doc_timbre_correction}


![音色校正](images/timbre_correction.png "音色校正")


该窗口为每一行显示听到的电平、目标和预期结果，并提供以下参数：

参考
: 校正的目标：:guilabel:`相邻根音符之间插值`、基于每侧多个相邻根音符的 :guilabel:`局部回归`，或 :guilabel:`与某个根音符对齐`（在该音符上演奏另一个根音符）。

校正音色（采样数据）
: 每一行的增益通过一条跟随音高的最小相位曲线应用到采样数据上：无论移调多少，校正在该分区的所有音符上都保持有效，循环也得以保留。立体声对中的两个采样会应用相同的校正。

校正电平（衰减）
: 通过分区的衰减来校正电平偏差，不会修改数据。如果衰减将变为负数，剩余部分会在满刻度范围内计入数据。

容差
: 某一行小于此值的偏差不予校正，只校正超出的部分。

强度
: 所校正的偏差占整个偏差的比例。

最大校正量
: 每一行的最大增益，提升和衰减两个方向各自适用。

校正的谐波
: 所有行，或仅从第 1 次到指定次数的谐波。

亮度、奇次谐波
: 加到目标上的斜率（正值使声音更明亮），以及加到目标的奇次谐波 3、5、7……上的电平。

:guilabel:`试听` 部分可以通过 :guilabel:`播放` 按钮比较原始声音（A）和校正后的声音（B）。
如果校正会超出满刻度，则降低采样的电平，并由衰减进行补偿。
当某个采样也被其他分区或乐器使用时，Polyphone 会询问是为校正的根音符创建该采样的副本，还是在所有位置修改它（可以记住该回答，直到关闭 Polyphone）。


## 调制器 {#doc_modulator}


乐器编辑页面的下部用于创建调制器，可以作用于整个乐器，也可以只作用于某个分区。
演奏乐器时，调制器会监听一个或两个 MIDI 信号，并根据所配置的数学规则修改表格中的某个参数。
一个调制器的输出也可以作为另一个调制器的输入（该功能出现在 [sf2 格式](manual/annexes/the-different-soundfont-formats.md#doc_sf2)的 2.04 版中，某些合成器可能不支持）。


![调制器编辑器](images/modulator_editor_2.png "调制器编辑器")


左侧的按钮用于：

* 展开 / 折叠调制器区域，
* 添加 / 删除调制器，
* 复制 / 粘贴 / 创建一个或多个调制器的副本。

添加调制器后，表格中对应单元格的边框会变粗（见上图 :guilabel:`全局` 列中的调音单元格）。

只有在选中单个分区时，才会显示该分区（或全局分区）的调制器。
折叠该部分时，会显示一个摘要，列出调制器的数量及其修改的参数。
在表格中选中单元格，会选中作用于对应参数的调制器，反之亦然。

每个调制器从左到右由以下元素组成：

信号源
: 第一个信号源是一个 MIDI 信号：所演奏音符的力度或音符编号、复音压力、通道压力、弯音轮、弯音轮灵敏度，或某个 MIDI 控制器（:guilabel:`CC`）。
  它也可以是一个或多个其他调制器的输出（:guilabel:`链接`），即以本调制器为目标的那些调制器。
  第二个信号源是可选的，用于修改第一个信号源的效果。

曲线
: 每个信号源旁边都有一个按钮，可打开曲线网格，用于选择信号的转换方式：线性、凹形、凸形或开关型，递增或递减，单极（从 0 到 1）或双极（从 -1 到 1）。

调制量
: 调制的最大幅度。

变换
: :guilabel:`无操作` 或 :guilabel:`绝对值`（使用调制结果的绝对值）。

目标
: 调制器所修改的参数，或另一个调制器（:guilabel:`调制器`）。
  目标下方的文字表示调制的范围：加到参数上的值（:guilabel:`相加，从` … :guilabel:`到`）或施加于参数的系数（:guilabel:`相乘，从` … :guilabel:`到`）。

如果某个调制器与列表中位于其上方的调制器完全相同，会显示 :guilabel:`被 … 覆盖` 字样。
在乐器层级，:guilabel:`覆盖 默认调制器` 表示该调制器取代了 sf2 格式的某个[默认调制器](manual/soundfont-editor/tools/instrument-tools.md#doc_default_mod)，而 :guilabel:`禁用 默认调制器` 表示其调制量为 0（此时该默认调制器被关闭）。
