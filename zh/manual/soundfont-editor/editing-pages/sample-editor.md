在[树状图](manual/soundfont-editor/tree.md)中单击一个或多个采样时，会出现采样编辑页面。

该页面分为以下几个部分：

* 表示采样的[波形图](#doc_graph)，
* [信息](#doc_info)区域，
* [频率](#doc_freq)分析，
* [均衡器](#doc_eq)，
* 采样[播放器](#doc_player)。


![采样页面](images/edit_sample.png "采样页面")


## 波形图 {#doc_graph}


### 缩放和平移


波形图用于查看声音的波形。
按住鼠标右键并拖动，可以在垂直或水平方向缩放：

* 向右拖动会放大水平轴，
* 向左拖动会缩小水平轴，
* 向上拖动会放大垂直轴，
* 向下拖动会缩小垂直轴。

如果水平轴已被放大，按住鼠标左键可以水平平移波形图。
鼠标滚轮也可以水平滚动波形图。


### 循环位置和播放位置


绿色竖线表示循环的起始位置（在波形图上单击左键可修改），红色竖线表示循环的结束位置（在波形图上单击右键可修改）。
每条竖线都配有一条表示部分波形的虚线，便于直观地查看循环起点和终点处波形的重叠情况。

播放时，一条白色竖线会在波形图上移动，实时指示播放位置。


### 剪切采样


按住 :kbd:`Alt` 键，可以定义一个要剪切的区域：

* 按下鼠标左键定义区域的起点，
* 松开鼠标左键定义区域的终点。

定义区域后，会弹出一个对话框，在剪切采样前请求确认。
选择 :guilabel:`是并创建另一个采样` 会剪切采样，同时用被剪掉的部分创建一个新的采样。


![剪切采样](images/cutting_sample.png "剪切采样")


### 波形图的颜色


波形图的颜色可以在软件[设置](manual/settings.md#doc_interface)中修改。


## “信息”部分 {#doc_info}


:guilabel:`信息` 部分可以查看（大多数情况下也可以编辑）以下信息：

大小
: 显示采样值的数量以及对应的时长（秒）。

循环点
: 可以在这里修改循环的起点和终点。
  有一个按钮可以设置起点和终点，使循环覆盖整个采样。

调音
: 可以调整采样的根音符及其校正值（以音分为单位），使声音按平均律调准。
  有一个按钮可以设置根音符和校正值，使其与估算的[频率](#doc_freq)一致。

采样率
: 任何修改都会触发重采样，以保持声音的音高不变。

通道
: 在 :guilabel:`单声道`、:guilabel:`左`、:guilabel:`右` 或 :guilabel:`链接` 中选择类型。
  如果类型为 :guilabel:`左`、:guilabel:`右` 或 :guilabel:`链接`，可以选择 :guilabel:`单声道` 取消立体声。
  选择 :guilabel:`单声道` 后，要恢复立体声状态，需要选择一个链接的采样。

链接
: 选择要链接的采样，使声音成为立体声。
  选择一个采样后，其类型会变为 :guilabel:`链接`（之后可以将此类型改为 :guilabel:`左` 或 :guilabel:`右`）。

如果音色库启用了[压缩](manual/soundfont-editor/editing-pages/editing-of-the-general-information.md#doc_edit)（[sf3 格式](manual/annexes/the-different-soundfont-formats.md#doc_sf3)），则对于尚未压缩的采样会显示一个压缩按钮。
压缩时，会弹出对话框要求选择压缩质量（:guilabel:`高`、:guilabel:`中` 或 :guilabel:`低`）。
压缩可能会改变采样的循环。\
**注意：**编辑采样时（应用滤波器、裁剪、放大等）会自动解压缩。

![选择压缩质量](images/sample_compress_dialog.png "选择压缩质量")

如果在[设置](manual/settings.md#doc_general)中勾选了 :guilabel:`立体声编辑` 选项（或使用窗口右下角的按钮），对立体声采样所做的任何修改都可以同时应用到链接的采样。
通过在[树状图](manual/soundfont-editor/tree.md)中多选，可以同时编辑多个采样。


## 频率分析 {#doc_freq}


频率分析包括傅里叶变换（显示信号中所含各频率强度的图表）。

![傅里叶图](images/fourier_graph.png "傅里叶图")

右侧显示主要峰值的列表，包含以下信息：

* 峰值强度与最大峰值强度之比，
* 频率，
* 最接近的对应音符，
* 校正值（与最接近的对应音符之间的差距）。

根据这些数据可以估算出声音的音高。
这个估算值可用于调音。

在图表上单击右键会打开一个右键菜单，可以：

* 将图表导出为 .png 图像，
* 显示所有峰值的列表，以及一个用于将该列表导出为 .csv 文件的按钮。

![显示峰值频率](images/tool_show_peak_frequencies.png "显示峰值频率")


## 均衡器 {#doc_eq}


均衡器可以将某些频率提升或衰减 -15 到 15 dB。
启用 :guilabel:`预览` 选项后可以试听效果，然后按 :guilabel:`应用` 按钮正式应用该效果。
按 :guilabel:`重置` 会将所有滑块归零到 0 dB（但不会移除已经应用到声音上的效果：要移除它，请使用[工具栏](manual/soundfont-editor/toolbar.md#doc_edit)中的 :guilabel:`撤销` 按钮）。

如果在[设置](manual/settings.md#doc_general)中勾选了相应选项，对立体声采样所做的任何修改都会自动应用到链接的采样。


## 播放器 {#doc_player}


播放器用于播放声音。
播放时，一个白色光标会在波形图上移动，指示播放位置。
播放选项包括：

循环
: 如果设定了循环的起点和终点，则循环播放声音。

立体声
: 以立体声方式播放采样及其链接的采样。
  如果同时要求循环，则使用两个采样各自的循环（它们可以不同）。

正弦
: 在声音中加入一个正弦校准信号，可以将采样调准到百分之一个半音的精度。
  首先需要填写根音符。
  此时，如果正弦波的频率与声音的基频略有差异，就能听到拍频。
  接下来只需精细调整校正值，使拍频尽可能慢，从而让采样尽可能准确。
  更多信息请参阅教程“[如何准备采样](tutorials/how-to-prepare-a-sample.md)”。

一个滑块用于设置播放音量（此音量不会保存在音色库中）。

如果在播放过程中通过[树状图](manual/soundfont-editor/tree.md)切换到另一个采样，播放会自动重新开始。
此外，当焦点在树状图上时，按 :kbd:`Space` 键可以开始或停止播放。
