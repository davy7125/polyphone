在[树状图](manual/soundfont-editor/tree.md)中选中一个乐器或它的某个分区时，[工具菜单](manual/soundfont-editor/tools/index.md)中包含若干工具，分为 4 个类别：

* [分析](#doc_cat_analyze)，
* [快速编辑](#doc_cat_fast)，
* [调制器](#doc_cat_mod)，
* [变换](#doc_cat_transformation)。

除了创建和弦、创建混合音栓以及显示参数之外，其他工具都可以通过多选同时用于多个乐器。


## 分析 {#doc_cat_analyze} 


### 显示参数 {#doc_display}


此工具显示某个参数随音符的变化情况。
图例区分了全局分区中定义的值、各分区中定义的值以及该参数的默认值。
可以使用对数刻度（注意小于或等于 0 的值！）。


![显示参数工具](images/tool_display_parameters.png "显示参数工具")


## 快速编辑 {#doc_cat_fast}


### 更改衰减 {#doc_attenuation}


该工具会计算所有选中乐器中的最小衰减和最大衰减，并允许你为所有衰减值加上一个偏移量，而不超出限值。

例如，如果所选乐器各分区中的最小衰减为 16 dB，而期望的最小衰减为 5 dB（以提高整体音量），那么所有乐器的所有分区的衰减都可以降低 11 dB。


![更改衰减工具](images/tool_change_attenuation.png "更改衰减工具")


### 失谐 {#doc_detune}


此功能会使乐器的音符轻微失谐，与一个音准正确的乐器一起使用时，可以产生波动效果。
效果的强度以每秒拍频数表示，并且可以调整：

* 音符 60（即键盘中央的“C”）处的每秒拍频数（该数值的正负号决定失谐的方向）；
* 拍频数随音符的变化：每隔一个八度，拍频数除以或乘以一个恒定系数（值为“1”表示整个键盘上的拍频数保持不变）。


![失谐工具](images/tool_detune.png "失谐工具")

### 基于音符的配置 {#doc_global}


此工具可以根据每个分区的音符范围，同时编辑乐器所有分区的某个参数。


![基于音符的配置工具](images/tool_keybased_configuration.png "基于音符的配置工具")


图形表示修改的强度：最左边的第一个值对应应用于包含音符 0 的分区的修改，最右边的最后一个值对应应用于包含音符 127 的分区的修改。
图形的最小值和最大值可以调整。
通过更改模式，可以编辑曲线：

手动
: 用鼠标绘制曲线。

线性上升 / 线性下降
: 曲线为一条直线。

指数上升 / 指数下降
: 曲线为指数曲线，其弯曲程度由 :guilabel:`刚度` 参数决定。

随机
: 根据 :guilabel:`分布` 参数随机生成数值。

使用线性或指数规律时，在图形中单击左键可设定线性或指数区域的起点，单击右键可设定终点。

要修改的参数在 :guilabel:`参数` 中选择，修改类型在 :guilabel:`修改` 中选择：

加
: 将修改值加到所选参数的值上。

乘
: 将修改值与所选参数的值相乘。

替换
: 用修改值替换所选参数的值。

可以只对力度范围位于某个特定范围内的分区应用修改，例如钢琴有多个力度层时，这会很有用。


### 自然释音 {#doc_release}


此工具为乐器的每个分区创建释音。
释音时间根据前两个参数计算（音符 36 的释音时长，以及两个相邻八度之间的系数 :guilabel:`到下一个八度的除数`），还可以通过第三个参数（:guilabel:`引起的失谐`）加入音高变化。


![自然释音工具](images/tool_natural_release.png "自然释音工具")


### 采样自动定位 {#doc_position}


软件会确定乐器所有分区的音符范围，以便优化它们在整个键盘上的使用。
当根音符不同的多个采样被绑定到一个空乐器时，也会自动执行此操作。


### 声音空间化 {#doc_spatialization}


此功能根据音高对声音进行空间分布，例如对钢琴很有用（低音和高音从左到右分布）。


![声音空间化工具](images/tool_sound_spatialization.png "声音空间化工具")


图中的每根竖条代表一根琴弦或一根音管，其长度与音高相关。
最短的竖条对应最高的音，最长的竖条对应最低的音。

每个音符都被放置在空间中的某个位置：最左端对应来自左侧的声音，最右端对应来自右侧的声音。
可以选择以下几种模式：

上升
: 高音在左侧，低音在右侧。

下降
: 低音在左侧，高音在右侧。

空洞
: 低音位于两端，高音居中。

尖峰
: 高音位于两端，低音居中。

随机
: 高音和低音随机分布。

还有其他选项可用：

* 模式的重复次数（:guilabel:`划分数`），
* 效果强度（:guilabel:`扩散`），
* 分区的填充（:guilabel:`填充`），
* 扩散不为 100% 时的左右偏移（:guilabel:`偏移`），
* :guilabel:`倒置`。

每次更改设置时，图形都会更新，便于直观查看。
鼠标悬停时，会显示音符编号与声像之间的对应关系。


### 移调 {#doc_transpose}


移调工具可以对整个乐器进行移调。
乐器的声音保持不变，但在键盘上的位置不同。

需要输入以半音为单位的移位量。
要使音高升高，移位量必须为正值。
反之，要使音高降低，移位量必须为负值。
对于乐器的每个分区，该工具执行的操作如下：

* 调整根音符，
* 如果移调的半音数带有小数，则修改微调值，
* 如果勾选了 :guilabel:`调整音符范围`，则按半音数平移音符范围。


![移调工具](images/tool_transpose_inst.png "移调工具")


## 调制器 {#doc_cat_mod}


### 覆盖默认调制器 {#doc_default_mod}


每个乐器都会被自动分配默认调制器。
此工具会显示这些调制器的列表，并可以创建调制器来覆盖或禁用所选的默认调制器（:guilabel:`覆盖` 和 :guilabel:`禁用` 按钮）。


![覆盖工具](images/tool_default_mod.png "覆盖工具")


### 移除调制器 {#doc_remove_mod}


所有选中乐器的所有调制器都会被移除。
会有一条消息提示删除了多少个调制器。

**注意：**默认调制器仍然会生效。
禁用默认调制器的唯一方法，是用“[覆盖默认调制器](#doc_default_mod)”工具将其覆盖。


## 变换 {#doc_cat_transformation}


### 创建和弦 {#doc_chords}


以一个乐器为基础，此工具可以创建所有可能的和弦。
例如，这在制作合唱或铺底音色时会很有用。

和弦的定义包括：选择它包含哪些音（根音、三度音、五度音、七度音和九度音）及其性质（大、小、纯、减、增）、转位次数以及八度。
包含和弦的采样可以针对每个音符、每 3 个音符或每 6 个音符创建，可选自动循环，可选单声道或立体声。


![创建和弦工具](images/tool_create_chords.png "创建和弦工具")

### 分区复制 {#doc_division}


此操作会复制乐器的所有分区。
例如，如果某个链接到乐器的采样的音符范围为 36-38，软件会复制这个分区，使该采样分别对应音符范围 36-36、37-37 和 38-38。
这样就可以针对每个不同的音符细致地编辑采样的各项参数，而不是以相同参数编辑整个分区。

也可以按力度范围复制分区。
没有采样的乐器不适用此工具。


![分区复制工具](images/tool_division_duplication.png "分区复制工具")


### 混合音栓创建 {#doc_mixture}


此工具专用于管风琴，可以基于现有乐器创建混合音栓。
会出现一个界面，用于指定混合音栓的各个分区，以及每个分区的列（音列）。
可选的列类型非常丰富，从八度一直到第 27 泛音。


![混合音栓创建工具](images/tool_mixture.png "混合音栓创建工具")


该工具在工作时，依据的是与所选乐器关联的所有采样、为每个采样定义的范围以及对应的衰减。
采样必须独立于乐器的定义进行调音（通过[采样编辑器](manual/soundfont-editor/editing-pages/sample-editor.md)），并且所指定的根音符不能考虑其所属的音栓（例如，如果声音是 4' 主音栓，则不进行移调）。

一个选项可以为所创建的采样自动设置循环，另一个选项用于设定采样的创建间隔（每个音符、每 3 个音符或每 6 个音符）。
最后，还可以选择所创建声音的类型：单声道或立体声。
